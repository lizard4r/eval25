## 🏆 Best Practice (BP) 사례

### BP 1. 독립예술영화 관객 비중 도전적 목표 초과달성

| 구분 | 내용 |
|------|------|
| **성과** | 전체 대비 독립예술영화 관객 비중 7.4% (목표 7.0% 대비 +0.4%p) |
| **요인** | 유통 종합지원 강화 + 유통 방식 다변화 |
| **의의** | 영화문화 다양성 확대에 기여 |

### BP 2. 국민 영화관람 활성화 할인권 사업 압도적 성과

| 구분 | 내용 |
|------|------|
| **성과** | 문화소비 쿠폰 중 소진 속도·소진률 **1위** |
| **요인** | 신속한 배포, 자동 지급 방식 도입, 효율적 홍보 |
| **파급효과** | 전년 동기 대비 관객 수 9.6%↑, 매출액 12.2%↑ |

### BP 3. 가치봄 제작예산 대비 효율성 극대화

| 구분 | 내용 |
|------|------|
| **성과** | 경영평가 '문화소외계층 관람환경 개선사업(4점)' **만점** 달성 |
| **요인** | 제작 노하우 활용 비용 절감 + 지역미디어센터 협업 |

### BP 4. 한국노인인력개발원 협업 혁신

| 구분 | 내용 |
|------|------|
| **혁신성** | 노인일자리 창출 + 동시관람 장비 관리 안정화 동시 달성 |
| **성과** | 보건복지부 전국화 심사 통과 → '26년 전국 확대 예정 |
| **사회적 가치** | 일자리 창출 + 장애인 문화접근성 제고 시너지 |
