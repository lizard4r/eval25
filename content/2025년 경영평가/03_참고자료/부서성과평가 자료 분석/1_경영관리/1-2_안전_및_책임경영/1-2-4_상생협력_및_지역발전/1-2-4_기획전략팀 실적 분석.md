## 📋 기획전략팀 미션 및 핵심과제

> **예산운용, 전략기획 및 고객관리**
> - 안정적 예산 운용 및 중장기 재원 조성

> - 내·외부 고객 서비스 개선 및 만족도 향상

| **G (지배구조)** | 국민참여예산 제도 운영으로 투명성 강화 |
| **S (사회)** | 중증장애인 생산품 우선 구매 실적 제고 |

## 🤝 국민참여예산 제도 운영 ⭐

### 1. 제도 개요

| 항목 | 내용 |
|------|------|
| **제도명** | KOFIC 국민참여예산 |
| **목적** | 참여 활성화, 재정 운영 투명성 제고 |
| **프로세스** | 제안 접수 → 검토 및 심사 → 사업 선정 → 예산 확정 |

### 2. 운영 현황

| 구분 | 실적 |
|------|------|
| **운영 기간** | **8년 연속** (2018~2025) |
| **누적 접수** | **98개 사업** |
| **반영 검토** | **14개 사업** |
| **최종 반영** | **2개 사업** |

### 3. 2025년 운영 실적

#### KOFIC 국민참여예산 (기존 채널)
| 항목 | 내용 |
|------|------|
| **제안의견** | 독립 및 저예산영화 장비 보험 사업 도입 |
| **접수채널** | KOFIC 홈페이지 통한 의견 접수 |
| **선정사업** | 영상장비 공공 보유지원 사업 |
| **예산반영 경과** | 2026년 부처안 반영 (정부안 미반영) |

#### 기획재정부 국민참여예산 (추가 채널) ⭐ (신규)
| 항목 | 내용 |
|------|------|
| **제안의견** | 독립영화 지방 상영 확대 |
| **접수채널** | 기재부 채널 통한 의견 접수 |
| **선정사업** | 독립예술영화 상영 프로그램 운영 사업 |
| **예산반영 경과** | **2026년 정부안 반영** (최종예산 반영 검토) |

### 4. 제도 고도화 성과

| 구분 | 내용 |
|------|------|
| **채널 다각화** | 기재부 국민참여예산 제도 추가 활용 |
| **정부안 반영** | 독립예술영화 상영 프로그램 운영 사업 **18억원 신규 편성** |
| **적극행정** | 선정사업 고도화 시행, 정책 연구과제 채택 |

## 🏢 중증장애인 우선구매 지표 개발 ⭐ (신규)

### 1. 추진 배경

| 항목 | 내용 |
|------|------|
| **법적 근거** | 「중증 장애인 우선구매 특별법」 준수 |
| **필요성** | 우선구매 실적 제고를 위한 인식 개선 및 구매 독려 필요 |
| **협력 부서** | 재무회계팀 |

### 2. 신규 지표 개발

| 항목 | 내용 |
|------|------|
| **지표명** | 우선구매 실적 (신규) |
| **해당 팀** | 전체 부서 |
| **지표 정의** | 중증장애인 생산품 구매실적 관리<br>① 홍보물, 인쇄물 총구매 대비 우선구매 금액비율 10%당 0.1점 가점<br>② 홍보물, 인쇄물 외 우선구매 실적 100만원 당 0.1점 가점 |
| **시행 시기** | **2025년 성과평가부터 시행 확정** |

### 3. 추진 프로세스

```
부서 제안 → 소관부서 검토 및 시뮬레이션 → 지표 개발 및 편람 반영 → 편람 확정 후 전사 통보
```

### 4. 기대 효과

- 중증장애인 생산품 **우선구매 실적 제고**
- 사회적 책임 이행을 통한 **ESG 경영 강화**
- 전 부서 **상생협력 의식 제고**
