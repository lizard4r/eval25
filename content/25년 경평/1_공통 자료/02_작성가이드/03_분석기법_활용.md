# 제3장. 분석기법 활용

> [!abstract] 이 장의 목표
> 경영실적보고서 작성에 필요한 다양한 분석 기법을 습득하여, 논리적이고 설득력 있는 보고서를 작성할 수 있는 역량을 확보한다.

---

## 3.0 분석기법, 왜 필요한가?

> [!note] 쉽게 말하면
> **분석기법 = 평가위원을 설득하는 "논리적 무기"**
>
> 평가위원은 하루에 수십 개 기관의 보고서를 읽습니다. "열심히 했다", "성과가 좋다"는 말로는 설득되지 않습니다. **숫자와 논리로 증명**해야 합니다.
>
> 분석기법을 활용하면:
> - ❌ "영화산업 발전에 기여했다" (주장만)
> - ✅ "제작지원 50편 → 관객 1,200만 명, 수출 32억 원 달성" (증거)

### 분석기법 활용의 3가지 효과

| 효과 | 설명 | 예시 |
|------|------|------|
| **논리성** | 왜 이 사업을 했는지 설명 | SWOT 분석으로 전략 수립 근거 제시 |
| **객관성** | 주장이 아닌 데이터로 증명 | 전년 대비 20% 증가, 동종기관 대비 1위 |
| **체계성** | 일관된 구조로 가독성 향상 | 투입→과정→산출→결과 단계별 설명 |

### 상황별 적합한 분석기법

| 이런 상황에서 | 이 분석기법을 사용 |
|---------------|-------------------|
| "왜 이 사업을 했나요?" | **환경분석** (SWOT, PEST) |
| "목표를 달성했나요?" | **성과분석** (목표-실적 비교) |
| "작년보다 나아졌나요?" | **시계열 비교분석** |
| "다른 기관보다 잘했나요?" | **동종기관 비교분석** |
| "정부 정책에 기여했나요?" | **정책연계 분석** |
| "문제를 어떻게 해결했나요?" | **근본원인분석** (5 Whys) |
| "효율적으로 했나요?" | **비용효과분석** |

## 3.1 환경분석 기법

### 3.1.1 환경분석의 목적

> [!note] 쉽게 말하면
> **환경분석 = "왜 이 사업을 했는지" 설명하는 도구**
>
> 평가위원의 첫 번째 질문: "왜 이 사업을 추진했습니까?"
>
> 환경분석으로 답할 수 있습니다:
> - "OTT 확산으로 극장 관객이 줄어드는 상황에서" (위협)
> - "우리가 가진 영화인 네트워크를 활용하여" (강점)
> - "중급 영화 제작지원을 확대했습니다" (전략)

```
환경분석 → 전략수립 → 사업추진 → 성과창출 → 환류개선
   │           │           │           │           │
   └───────────┴───────────┴───────────┴───────────┘
              논리적 연결고리 = 설득력
```

### 3.1.2 SWOT 분석

> [!note] 쉽게 말하면
> **SWOT = 우리 상황을 4가지로 정리하는 방법**
>
> - **S**trength (강점): 우리가 잘하는 것
> - **W**eakness (약점): 우리가 부족한 것
> - **O**pportunity (기회): 외부에서 오는 좋은 기회
> - **T**hreat (위협): 외부에서 오는 나쁜 위험

| 구분 | 내부 요인 (우리 안) | 외부 요인 (우리 밖) |
|------|-------------------|-------------------|
| **좋은 것** | S (강점) | O (기회) |
| **나쁜 것** | W (약점) | T (위협) |

#### 영진위 SWOT 분석 예시

| 강점 (S) - 우리가 잘하는 것 | 약점 (W) - 우리가 부족한 것 |
|---------------------------|---------------------------|
| • 영화산업 50년 전문성 보유 | • 기금 재원 감소 (입장권 부과금↓) |
| • 통합전산망 데이터 인프라 구축 | • 급변하는 OTT 환경 대응 한계 |
| • 영화인 2만 명 네트워크 확보 | • 정원 대비 업무량 과다 |

| 기회 (O) - 외부의 좋은 기회 | 위협 (T) - 외부의 나쁜 위험 |
|---------------------------|---------------------------|
| • K-콘텐츠 글로벌 위상 강화 | • OTT 확산 → 극장 관객 감소 |
| • 정부 콘텐츠산업 지원 확대 | • 글로벌 콘텐츠 기업과의 경쟁 심화 |
| • AI 등 신기술 활용 가능성 | • 영화산업 투자 위축 지속 |

#### SWOT 교차분석: 전략 도출하기

> [!note] 쉽게 말하면
> **교차분석 = SWOT 4가지를 조합해서 전략 만들기**
>
> - SO전략: 강점으로 기회 잡기 (가장 좋은 상황)
> - ST전략: 강점으로 위협 막기
> - WO전략: 약점 보완해서 기회 잡기
> - WT전략: 약점 줄이고 위협 피하기

| 전략 | 조합 | 영진위 적용 예시 |
|------|------|-----------------|
| **SO전략** | 강점 + 기회 | 영화인 네트워크 활용 → K-영화 해외진출 지원 강화 |
| **ST전략** | 강점 + 위협 | 통합전산망 데이터 → OTT 시장분석 서비스 제공 |
| **WO전략** | 약점 + 기회 | 민간 협력 확대 → 정부 지원사업 공동 추진 |
| **WT전략** | 약점 + 위협 | 선택과 집중 → 핵심사업 효율화, 비핵심 축소 |

### 3.1.3 PEST 분석

> [!note] 쉽게 말하면
> **PEST = 외부 환경을 4가지 관점에서 보는 방법**
>
> 세상이 어떻게 변하고 있는지 큰 그림을 파악할 때 사용합니다.
> - **P**olitical: 정부가 뭘 하려고 하나?
> - **E**conomic: 경제 상황이 어떤가?
> - **S**ocial: 사람들이 뭘 원하나?
> - **T**echnological: 기술이 어떻게 변하나?

| 요인 | 분석 질문 | 영진위 적용 예시 |
|------|----------|-----------------|
| **P** 정치/정책 | 정부 정책 방향은? | 윤석열 정부 "문화강국" 국정과제, 콘텐츠산업 예산 확대 |
| **E** 경제 | 산업 경기는? | 영화산업 투자 규모 3년째 감소, OTT 시장 연 15% 성장 |
| **S** 사회 | 소비자 트렌드는? | MZ세대 숏폼 선호, 문화다양성 관심 증가 |
| **T** 기술 | 신기술 동향은? | 생성형 AI 활용, 버추얼 프로덕션, LED 스튜디오 |

#### PEST 분석 작성 예시

```
■ 사업환경 분석 (PEST)

 ○ (정책환경) 콘텐츠산업 지원 확대 기조 지속
    - 국정과제 "문화강국 도약"에 K-콘텐츠 육성 포함
    - '25년 영화분야 정부 예산 전년 대비 8.2% 증가

 ○ (경제환경) 영화산업 투자 회복 조짐
    - '24년 극장 관객수 1.5억 명 (전년비 +12%)
    - 다만, 코로나19 이전('19년) 대비 70% 수준

 ○ (사회환경) 콘텐츠 소비 패턴 다변화
    - OTT 이용률 72% (방송통신위 '24)
    - 문화다양성 영화 관심 증가 (독립·예술영화 점유율 상승)

 ○ (기술환경) 영화제작 기술 혁신 가속
    - 버추얼 프로덕션 도입 확산 (지원작 중 30% 활용)
    - AI 기반 시나리오 분석, 편집 자동화 시험 적용
```

### 3.1.4 환경분석 서술 템플릿

> [!tip] 복사해서 바로 사용하세요

```
■ 사업환경 분석

 ○ (외부환경) 환경 변화 및 시사점
    - (정책) [정부 정책 방향, 관련 법령, 국정과제]
    - (산업) [산업 동향, 시장 규모, 경쟁 상황]
    - (기술) [기술 변화, 신기술 등장, 활용 가능성]
    - (사회) [소비자 트렌드, 인구 변화, 사회적 요구]

 ○ (내부역량) 기관 역량 및 한계
    - (강점) [활용 가능한 핵심 역량 2~3개]
    - (약점) [보완이 필요한 영역 2~3개]

 ○ (전략방향) 환경분석 기반 추진전략
    - 환경변화 대응 방향: [핵심 대응 방향]
    - 중점 추진과제: [도출된 과제 2~3개]
```

## 3.2 성과분석 기법

### 3.2.1 로직모델 (Logic Model)

> [!note] 쉽게 말하면
> **로직모델 = "투입 → 산출 → 성과" 연결고리 보여주기**
>
> 평가위원이 알고 싶은 것: "예산을 썼는데 뭐가 좋아졌나요?"
>
> 로직모델로 답합니다:
> - **투입**: 예산 10억, 인력 5명 투입
> - **활동**: 제작지원 심사 50건 진행
> - **산출**: 30편 지원 (직접 결과물)
> - **결과**: 지원작 관객 500만 명 (효과)
> - **영향**: 한국영화 점유율 상승 (장기 파급효과)

```
[투입]      [활동]        [산출]       [결과]       [영향]
예산·인력 → 사업 수행 → 직접 결과물 → 단기 효과 → 장기 파급
   │           │           │           │           │
  10억      심사 50건    지원 30편   관객 500만  점유율 상승
```

| 단계 | 의미 | 질문 | 영진위 예시 |
|------|------|------|------------|
| **투입** | 무엇을 넣었나 | 얼마나 투입? | 예산 10억, 인력 5명 |
| **활동** | 무엇을 했나 | 어떤 활동? | 공모, 심사, 선정, 관리 |
| **산출** | 직접 결과물 | 몇 개 만들었나? | 지원 30편, 교육 500명 |
| **결과** | 단기 효과 | 어떤 변화? | 관객 500만, 수출 20억 |
| **영향** | 장기 파급 | 사회적 변화? | 영화산업 성장, 일자리 창출 |

#### 로직모델 작성 예시: 영화제작지원

```
■ 영화제작지원사업 성과 (로직모델)

┌─────────┬─────────┬─────────┬─────────┬─────────┐
│  투입   │  활동   │  산출   │  결과   │  영향   │
├─────────┼─────────┼─────────┼─────────┼─────────┤
│예산 50억│공모 운영│지원 30편│관객     │한국영화 │
│인력 8명 │심사 진행│제작 완료│1,200만 │점유율   │
│        │계약 관리│ 28편   │수출 32억│42% 달성│
└─────────┴─────────┴─────────┴─────────┴─────────┘

→ 투입 예산 대비 관객 효과: 1억 원당 24만 명
→ 지원작 중 손익분기점 도달: 18편 (60%)
```

### 3.2.2 정량적 성과분석

> [!note] 쉽게 말하면
> **정량분석 = 숫자로 성과 증명하기**
>
> "잘했다"가 아니라 "얼마나 잘했는지" 보여주는 것입니다.
>
> 3가지 방법:
> 1. **목표 대비**: 목표 50편, 실적 55편 = 달성률 110%
> 2. **전년 대비**: 작년 45편, 올해 55편 = 22% 증가
> 3. **추세 분석**: 3년간 연평균 15% 성장

#### 1) 목표 대비 달성률 분석

| 지표 | 목표 | 실적 | 달성률 | 평가 |
|------|------|------|--------|------|
| 제작지원 편수 | 50편 | 55편 | **110%** | ◎ 초과달성 |
| 국제영화제 진출 | 30건 | 28건 | **93%** | △ 소폭 미달 |
| 온라인 교육 이수 | 500명 | 612명 | **122%** | ◎ 대폭 초과 |

> [!tip] 달성률 표현 기준
> - **120% 이상**: ◎ 대폭 초과달성
> - **100~120%**: ○ 목표 달성 / 초과달성
> - **90~100%**: △ 소폭 미달 (원인분석 필요)
> - **90% 미만**: × 미달 (개선방안 필수)

#### 2) 전년 대비 증감 분석

| 지표 | '23년 | '24년 | 증감 | 증감률 |
|------|-------|-------|------|--------|
| 온라인 관람건수 | 1,200만 | 1,450만 | +250만 | **+20.8%** |
| 해외수출 계약 | 85건 | 102건 | +17건 | **+20.0%** |
| 영화인 복지혜택 | 8,500명 | 11,200명 | +2,700명 | **+31.8%** |

#### 3) 추세 분석 (3~5개년)

> [!note] 쉽게 말하면
> **추세분석 = 3년 이상 데이터로 "방향성" 보여주기**
>
> 1년치 성과는 우연일 수 있습니다. 3~5년간 꾸준히 좋아졌다면 실력입니다.

| 연도 | 지원 편수 | 전년비 | 누적 증감 |
|------|----------|--------|----------|
| 2021 | 35편 | - | 기준 |
| 2022 | 40편 | +14.3% | +5편 |
| 2023 | 45편 | +12.5% | +10편 |
| 2024 | 55편 | +22.2% | +20편 |

→ **4년간 연평균 성장률(CAGR)**: 16.3%

```
지원편수 추이 (2021~2024)

60│                    ★ 55편
  │                  ╱
50│              ╱
  │          ╱ 45편
40│      ╱ 40편
  │  ╱ 35편
30│
  └──────────────────────────
    2021   2022   2023   2024
```

### 3.2.3 정성적 성과분석

> [!note] 쉽게 말하면
> **정성분석 = 숫자로 표현 안 되는 성과 설명하기**
>
> 예: 국제영화제 수상, 언론 호평, 제도 개선 효과
>
> 주의: "잘했다" 대신 **구체적 사례**와 **외부 인정**으로 증명

#### 정성적 성과 서술 3원칙

| 원칙 | 나쁜 예 ❌ | 좋은 예 ✅ |
|------|-----------|-----------|
| **구체성** | 영화산업 발전에 기여 | 지원작 '파묘' 칸영화제 초청, 관객 1,200만 돌파 |
| **객관성** | 우수한 성과를 거둠 | 문체부 우수기관 선정, 국정감사 모범사례 보고 |
| **인과성** | 한국영화 해외진출 증가 | 마켓 참가지원(120편) → 해외판매 계약 102건 체결 |

#### 정성적 성과 증거 유형

| 증거 유형 | 예시 |
|----------|------|
| **수상 실적** | 칸·베니스·베를린 영화제 수상 |
| **외부 평가** | 문체부 평가 우수기관, 청렴도 1등급 |
| **언론 보도** | 긍정 보도 85건, 부정 보도 2건 |
| **이해관계자 만족도** | 영화인 만족도 4.2점/5점 |
| **제도화 성과** | 정책이 법령·제도로 채택 |

### 3.2.4 성과분석 서술 템플릿

```

 ○ (외부평가) 객관적 성과 인정
    - 문화체육관광부 우수사업 선정 ('24.○월)
    - 영화인 만족도조사 4.2점/5점 (전년 3.8점)
```

## 3.3 비교분석 기법

### 3.3.1 비교분석의 유형

> [!note] 쉽게 말하면
> **비교분석 = "다른 것과 비교해서" 좋다는 걸 증명하기**
>
> 4가지 비교 방법:
> 1. **시계열**: 과거의 나 vs 지금의 나 (성장했나?)
> 2. **목표**: 목표 vs 실적 (달성했나?)
> 3. **동종기관**: 비슷한 기관 vs 우리 (더 잘했나?)
> 4. **벤치마킹**: 최고 기관에서 배워서 적용 (개선했나?)

| 유형 | 비교 대상 | 활용 목적 | 설득 포인트 |
|------|----------|----------|------------|
| **시계열** | 과거 실적 | 개선 추이 입증 | "매년 좋아지고 있다" |
| **목표** | 설정 목표 | 달성도 평가 | "약속을 지켰다" |
| **동종기관** | 유사 기관 | 상대적 우수성 | "다른 곳보다 낫다" |
| **벤치마킹** | 우수 사례 | 개선 노력 | "배워서 적용했다" |

### 3.3.2 시계열 비교분석

> [!note] 쉽게 말하면
> **시계열 비교 = "예전보다 좋아졌다"를 숫자로 증명**
>
> 최소 3년, 가능하면 5년 데이터를 보여주세요.
> 1년만 좋으면 운일 수 있지만, 3년 연속이면 실력입니다.

#### 시계열 비교 예시: 청렴도 변화

| 연도 | 종합청렴도 | 외부청렴도 | 내부청렴도 | 등급 |
|------|-----------|-----------|-----------|------|
| 2021 | 7.82 | 8.12 | 7.45 | 3등급 |
| 2022 | 8.15 | 8.35 | 7.89 | 2등급 |
| 2023 | 8.42 | 8.58 | 8.21 | 2등급 |
| 2024 | 8.68 | 8.75 | 8.56 | **1등급** |

**분석 결과**:
- 4년간 종합청렴도 **0.86점 상승**
- 등급 **3등급 → 1등급** 2단계 도약
- 연평균 개선율: **2.7%**

### 3.3.3 동종기관 비교분석

> [!note] 쉽게 말하면
> **동종기관 비교 = "비슷한 기관보다 잘했다"를 증명**
>
> 주의사항:
> - 비교 가능한 기관 선정 (규모·성격 유사)
> - 공식 데이터 활용 (알리오 공시 등)
> - 맥락 설명 필수 (왜 차이가 나는지)

| 구분 | 영진위 | A기관 | B기관 | 평균 |
|------|--------|-------|-------|------|
| 정원(명) | 150 | 180 | 120 | 150 |
| 예산(억) | 1,200 | 1,500 | 900 | 1,200 |
| 지원건수 | **850** | 720 | 550 | 707 |
| 건당비용(억) | **1.4** | 2.1 | 1.6 | 1.7 |

**영진위 우수성**:
- 지원건수: 동종기관 평균 대비 **20% 많음**
- 건당비용: 동종기관 평균 대비 **18% 낮음** (효율성↑)

### 3.3.4 벤치마킹 분석

> [!note] 쉽게 말하면
> **벤치마킹 = "좋은 사례를 배워서 우리도 적용했다"**
>
> 4단계로 서술:
> 1. 어디를 벤치마킹했는지 (대상 선정)
> 2. 뭘 배웠는지 (우수 요인)
> 3. 어떻게 적용했는지 (도입 방법)
> 4. 결과가 어땠는지 (개선 효과)

#### 벤치마킹 분석 예시

```
■ 청렴문화 우수기관 벤치마킹

 ○ (대상선정) 국민권익위 청렴도 우수기관 A공단 선정
    - 선정사유: 3년 연속 1등급, 동일 업종 최고 수준

 ○ (우수요인) 청렴 마일리지 제도 운영
    - 청렴 활동 참여 시 마일리지 부여
    - 연말 마일리지 우수자 인센티브 제공
    - 전 직원 청렴문화 참여율 95%

 ○ (도입적용) '24년 청렴 마일리지 제도 도입
    - A공단 담당자 초청 설명회 ('24.3월)
    - 영진위 특성 반영 제도 설계 ('24.4월)
    - 전 직원 대상 시범운영 ('24.5월~)

 ○ (개선성과) 청렴문화 활동 참여율 향상
    - 청렴교육 이수율: 85% → 98% (+13%p)
    - 청렴 신고 건수: 0건 유지
    - 내부청렴도: 8.21 → 8.56 (+0.35점)
```

## 3.4 정책연계 분석

### 3.4.1 정책연계의 중요성

> [!note] 쉽게 말하면
> **정책연계 = "정부가 하라는 걸 우리가 했다"를 보여주기**
>
> 공공기관은 정부 정책을 실행하는 기관입니다.
> "정부 정책에 얼마나 기여했는가"가 핵심 평가 포인트입니다.
>
> 정책연계가 중요한 이유:
> 1. **정당성**: "왜 했나?" → "정부 정책이니까"
> 2. **성과 인정**: "뭘 했나?" → "국정과제 달성에 기여"
> 3. **가점**: 국정과제 이행실적은 가산점 반영

## 3.5 추가 분석기법 (심화)

### 3.5.1 갭분석 (Gap Analysis)

> [!note] 쉽게 말하면
> **갭분석 = "목표와 현실의 차이"를 분석하고 해결책 제시**
>
> 목표를 못 달성했을 때 특히 유용합니다.
> "왜 못했는지" + "어떻게 개선할지" 설명할 때 사용합니다.

```
갭분석 구조

[현재 상태] ───── 갭(차이) ─────▶ [목표 상태]
    85%           -15%p               100%
                    │
                    ▼
              [갭 발생 원인]
                    │
                    ▼
               [해결 방안]
```

#### 갭분석 예시: 목표 미달 설명

| 구분 | 내용 |
|------|------|
| **목표** | 영화인 복지 등록 15,000명 |
| **실적** | 12,750명 (달성률 85%) |
| **갭** | 2,250명 미달 (-15%p) |

| 갭 원인 | 분석 | 해결방안 |
|---------|------|----------|
| 홍보 부족 | 신규 영화인 인지도 낮음 | SNS 타겟 광고 확대 |
| 등록 절차 복잡 | 서류 제출 5종 필요 | 간소화(3종), 온라인화 |
| 혜택 인식 부족 | 복지혜택 내용 모름 | 혜택 안내 강화 |

### 3.5.2 근본원인분석 (5 Whys)

> [!note] 쉽게 말하면
> **5 Whys = "왜?"를 5번 반복해서 진짜 원인 찾기**
>
> 문제가 발생했을 때 표면적 원인이 아닌 근본 원인을 찾습니다.
> 근본 원인을 해결해야 문제가 재발하지 않습니다.

#### 5 Whys 예시: 지원사업 신청 감소

```
문제: 영화제작지원 신청이 전년 대비 20% 감소

1차 Why: 왜 신청이 줄었는가?
→ 답변: 중소 제작사 신청이 특히 감소

2차 Why: 왜 중소 제작사 신청이 줄었는가?
→ 답변: 신청 서류 준비 부담이 크다는 의견

3차 Why: 왜 서류 준비가 부담인가?
→ 답변: 사업계획서 외 재무제표, 경력증명 등 10종 필요

4차 Why: 왜 서류가 10종이나 필요한가?
→ 답변: 과거 부정수급 방지를 위해 강화

5차 Why: 왜 서류로만 검증하는가?
→ 답변: 다른 검증 방식 미도입

★ 근본원인: 서류 외 검증방식 부재
★ 해결방안:
   - 영화인 등록 DB 연계로 경력 자동 확인
   - 국세청 연계로 재무정보 간소화
   - 서류 10종 → 3종 축소
```

### 3.5.3 비용효과분석

> [!note] 쉽게 말하면
> **비용효과분석 = "투입 대비 효과가 얼마나 좋은가?"**
>
> 같은 예산으로 더 많은 성과를 냈다면 효율적입니다.
> "가성비"를 숫자로 증명하는 방법입니다.

| 지표 | 산식 | 영진위 실적 | 의미 |
|------|------|------------|------|
| **예산 대비 관객수** | 관객수 ÷ 예산 | 1억당 24만 명 | 예산 효율성 |
| **건당 지원비용** | 예산 ÷ 지원건수 | 건당 5,800만 원 | 단가 효율성 |
| **인력 대비 처리건수** | 처리건수 ÷ 인력 | 1인당 85건 | 업무 효율성 |

#### 비용효과분석 예시

| 구분 | '23년 | '24년 | 개선율 |
|------|-------|-------|--------|
| 지원예산 | 50억 | 55억 | +10% |
| 지원편수 | 30편 | 38편 | +27% |
| 관객수 | 800만 | 1,200만 | +50% |
| **편당 비용** | 1.67억 | **1.45억** | **-13%** |
| **예산당 관객** | 16만/억 | **22만/억** | **+38%** |

→ 예산은 10% 증가했으나, 편당 비용 13% 감소, 효율성 38% 향상

### 3.5.4 이해관계자 분석

> [!note] 쉽게 말하면
> **이해관계자 분석 = "누가 영향받는지" 정리**
>
> 사회적 가치 지표에서 특히 중요합니다.
> "국민에게 어떤 혜택이 갔는가?"를 보여줄 때 유용합니다.

| 이해관계자 | 관심사항 | 영진위 기여 | 성과지표 |
|-----------|---------|------------|----------|
| **영화인** | 제작 지원, 복지 | 제작지원, 4대보험 | 지원 38편, 복지등록 1.2만 명 |
| **관객** | 다양한 영화 관람 | 독립영화 배급지원 | 독립영화 상영 850편 |
| **극장** | 관객 유치, 운영지원 | 작은영화관 지원 | 30개소 운영지원 |
| **지역사회** | 문화향유 기회 | 찾아가는 영화관 | 12만 명 관람 |

### 3.5.5 Before & After 분석

> [!note] 쉽게 말하면
> **Before & After = "전에는 이랬는데, 지금은 이렇다"**
>
> 개선 효과를 가장 직관적으로 보여주는 방법입니다.
> 제도 개선, 프로세스 혁신 성과에 효과적입니다.

#### Before & After 분석 예시: 지원금 신청 절차 개선

| 구분 | Before (개선 전) | After (개선 후) | 개선 효과 |
|------|-----------------|-----------------|----------|
| **신청 방법** | 방문 또는 우편 | 온라인 전용 | 편의성 ↑ |
| **필요 서류** | 10종 | 3종 | 70% 감소 |
| **처리 기간** | 14일 | 5일 | 64% 단축 |
| **민원 건수** | 월 50건 | 월 8건 | 84% 감소 |
| **만족도** | 3.2점 | 4.5점 | 1.3점 상승 |

### 3.5.6 PDCA 사이클 분석

> [!note] 쉽게 말하면
> **PDCA = "계획-실행-점검-개선" 순환 보여주기**
>
> "한 번 하고 끝"이 아니라 "계속 개선하고 있다"를 증명합니다.
> 환류 체계, 지속적 개선 노력을 서술할 때 효과적입니다.

```
PDCA 순환 구조

    ┌──────────┐
    │   Plan   │  계획: 목표 설정, 방법 결정
    │  (계획)   │
    └────┬─────┘
         ▼
    ┌──────────┐
    │    Do    │  실행: 계획대로 수행
    │  (실행)   │
    └────┬─────┘
         ▼
    ┌──────────┐
    │  Check   │  점검: 결과 측정, 목표 대비 비교
    │  (점검)   │
    └────┬─────┘
         ▼
    ┌──────────┐
    │   Act    │  개선: 문제점 분석, 개선방안 도출
    │  (개선)   │
    └────┬─────┘
         │
         └──────▶ 다음 PDCA 사이클로 연결
```

#### PDCA 분석 예시: 영화인 복지사업

| 단계 | 내용 |
|------|------|
| **Plan** | '24년 복지등록 15,000명 목표 수립, 홍보 확대 계획 |
| **Do** | SNS 광고 집행, 영화제 현장 홍보 부스 운영 |
| **Check** | 12,750명 달성 (85%), 신규 등록자 분석 |
| **Act** | 미등록 원인 분석 → '25년 등록 절차 간소화, 혜택 확대 반영 |

## 3.6 분석기법 종합 활용

### 3.6.1 분석기법 선택 가이드

| 이런 질문에 답할 때 | 이 분석기법을 사용 |
|-------------------|-------------------|
| "왜 이 사업을 했나요?" | SWOT, PEST (환경분석) |
| "목표를 달성했나요?" | 목표-실적 비교, 달성률 분석 |
| "작년보다 나아졌나요?" | 시계열 비교, 추세분석 |
| "다른 기관보다 잘했나요?" | 동종기관 비교분석 |
| "정부 정책에 기여했나요?" | 정책연계 분석 |
| "왜 목표를 못 달성했나요?" | 갭분석, 5 Whys |
| "효율적으로 했나요?" | 비용효과분석 |
| "계속 개선하고 있나요?" | PDCA, Before & After |

### 3.6.2 지표별 분석기법 적용

| 지표 유형 | 권장 분석기법 | 활용 예시 |
|----------|-------------|----------|
| **경영전략** | 환경분석 + 정책연계 | SWOT 기반 전략수립, 국정과제 연계 |
| **사회적 가치** | 비교분석 + 이해관계자 | 청렴도 추이, 수혜자별 성과 |
| **조직인사** | Before & After + PDCA | 제도 개선 효과, 인사제도 환류 |
| **재무예산** | 비용효과 + 시계열 | 예산 효율성, 재무비율 추이 |
| **주요사업** | 로직모델 + 정책연계 | 투입-산출-성과, 정책기여도 |
| **계량지표** | 목표-실적 + 갭분석 | 달성률, 미달 원인분석 |

### 3.6.3 분석기법 조합 활용

> [!tip] 하나만 쓰지 말고 조합하세요
>
> 여러 분석기법을 조합하면 더 설득력 있습니다.
>
> **예시: 영화제작지원사업 성과 서술**
> 1. **환경분석**: OTT 확산 → 극장 위기 → 한국영화 지원 필요성 (PEST)
> 2. **정책연계**: 국정과제 "K-콘텐츠 육성" 이행
> 3. **성과분석**: 지원 38편, 관객 1,200만 (로직모델)
> 4. **비교분석**: 전년 대비 27% 증가 (시계열)
> 5. **비용효과**: 편당 비용 13% 감소 (효율성)

## 핵심 정리

> [!summary] 제3장 핵심 정리
>
> **1. 환경분석 기법**
> - SWOT: 강점·약점·기회·위협 분석 → 교차분석으로 전략 도출
> - PEST: 정치·경제·사회·기술 거시환경 분석
> - 목적: "왜 이 사업을 했는지" 논리적 근거 제시
>
> **2. 성과분석 기법**
> - 로직모델: 투입 → 활동 → 산출 → 결과 → 영향
> - 정량분석: 목표달성률, 전년비, 추세분석
> - 정성분석: 구체성·객관성·인과성 원칙 준수
>
> **3. 비교분석 기법**
> - 시계열: 3~5년 데이터로 개선 추이 입증
> - 동종기관: 상대적 우수성 입증 (공식 데이터 활용)
> - 벤치마킹: 우수사례 도입 → 적용 → 성과 연결
>
> **4. 정책연계 분석**
> - 국정과제 → 정부정책 → 부처정책 → 기관정책 연계
> - 정책-사업-성과 연결고리 명확화
>
> **5. 심화 분석기법**
> - 갭분석: 목표-실적 차이 원인 분석
> - 5 Whys: 근본원인 도출
> - 비용효과: 효율성 증명
> - Before & After: 개선 효과 시각화
> - PDCA: 지속적 개선 체계 서술
