# 제4장. 서술 기법

> [!abstract] 이 장의 목표
> 경영실적보고서의 효과적인 서술 방법을 습득하여, 평가위원이 핵심 내용을 빠르게 파악하고 긍정적으로 평가할 수 있는 보고서를 작성한다.

---

## 4.0 서술 기법을 왜 알아야 할까?

> [!tip] 쉽게 말하면
> 경영평가 보고서는 **"같은 내용도 어떻게 쓰느냐에 따라 점수가 달라집니다."**
>
> 평가위원은 수십 개 기관의 보고서를 짧은 시간에 읽습니다. 핵심을 빠르게 찾을 수 있고, 성과가 눈에 들어오는 보고서가 좋은 점수를 받습니다.

### 좋은 보고서 vs 나쁜 보고서

| 구분 | 나쁜 보고서 | 좋은 보고서 |
|------|------------|------------|
| **구조** | 장황한 서술, 핵심 찾기 어려움 | 개조식, 핵심이 눈에 띔 |
| **표현** | "다양한 노력", "적극 추진" | "12회 실시", "목표 대비 115%" |
| **수치** | 실적만 나열 | 목표-실적-달성률-전년비 비교 |
| **성과** | 숨어 있음 | 태그, 볼드체로 강조 |

## 4.1 개조식 작성 원칙

### 4.1.1 개조식이란?

> [!tip] 쉽게 말하면
> **개조식 = 핵심만 간결하게 항목별로 쓰는 것**
>
> 소설처럼 문장을 이어 쓰지 않고, 핵심 내용을 **기호(○, -, ·)로 구분**해서 씁니다. 평가위원이 **3초 만에 핵심을 파악**할 수 있어야 합니다.

| 구분 | 서술식 | 개조식 |
|------|--------|--------|
| 형태 | 완결된 문장을 이어서 씀 | 항목별로 핵심만 나열 |
| 장점 | 맥락 전달에 유리 | 핵심 파악이 빠름 |
| 적합한 곳 | 배경 설명, 서론 | 실적·성과 제시 |

### 4.1.2 개조식 4대 원칙

```
① 두괄식: 결론(핵심)을 먼저 쓰고, 설명은 뒤에
② 병렬구조: 같은 수준의 항목은 같은 형식으로
③ 간결성: 한 항목에 한 가지 내용만
④ 계층성: 대→중→소 논리적 구조로
```

### 4.1.3 기호 체계 (반드시 통일)

```
■ 지표명/대제목 ─────────────────────────────

 ○ (중제목) 핵심 내용 요약
    - (소제목) 세부 내용 1
    - (소제목) 세부 내용 2
      · 상세 내용 a
      · 상세 내용 b
    ※ 참고사항, 주석
```

| 수준 | 기호 | 용도 | 예시 |
|------|------|------|------|
| 1수준 | ■ | 지표명, 대제목 | ■ 윤리경영 노력과 활동 |
| 2수준 | ○ | 평가항목, 중제목 | ○ (추진체계) 전담조직 구성 |
| 3수준 | - | 세부내용, 실적 | - 윤리경영위원회 연 4회 운영 |
| 4수준 | · | 상세내용, 부연 | · 외부위원 3명 포함 총 7명 |
| 5수준 | ※ | 주석, 참고 | ※ 전년 2회 대비 2회 증가 |

### 4.1.4 실제 작성 예시 비교

> [!example] 똑같은 내용, 다른 인상

**❌ 서술식 (읽기 힘듦)**
```
영화진흥위원회는 윤리경영을 체계적으로 추진하기 위하여
윤리경영위원회를 구성하여 운영하고 있으며, 동 위원회는
외부위원 3명을 포함한 총 7명으로 구성되어 있고, 2024년에는
총 4회의 회의를 개최하여 청렴시책 점검, 갑질 예방대책 등
주요 안건을 심의하였습니다.
```

**✅ 개조식 (핵심이 눈에 들어옴)**
```
○ (추진체계) 윤리경영위원회 운영
   - 구성: 외부위원 3명 포함 총 7명
   - 운영: '24년 4회 개최 (전년 2회 대비 +2회 ↑)
   - 심의: 청렴시책 점검, 갑질 예방대책 등 12건
```

## 4.2 문장 작성 4대 원칙

### 4.2.1 간결-명확-객관-구체

> [!tip] 쉽게 말하면
> 모든 문장은 **"숫자로 증명"**하고, **"50자 이내"**로 씁니다.

```mermaid
flowchart LR
    A[간결하게<br/>50자 이내] --> B[명확하게<br/>모호함 제거]
    B --> C[객관적으로<br/>수치로 증명]
    C --> D[구체적으로<br/>누가·무엇·얼마나]
```

| 원칙 | 나쁜 예 | 좋은 예 |
|------|---------|---------|
| **간결** | "~하기 위하여 ~을 통해 ~한 결과" | "~실시 → 결과 달성" |
| **명확** | "다수의 영화인" | "영화인 1,500명" |
| **객관** | "우수한 성과" | "목표 대비 120% 달성" |
| **구체** | "적극 노력함" | "교육 12회 실시, 450명 참여" |

### 4.2.2 문장 구조 개선법

#### 피동태 → 능동태

| ❌ 피동태 | ✅ 능동태 |
|----------|----------|
| 사업이 추진되었음 | 사업을 추진함 |
| 제도가 개선되었음 | 제도를 개선함 |
| 성과가 창출되었음 | 성과를 창출함 |

#### 서술형 → 명사형

| ❌ 서술형 | ✅ 명사형 |
|----------|----------|
| 교육을 실시하였습니다 | 교육 실시 (12회, 450명) |
| 점검을 수행하였습니다 | 점검 수행 (분기별 4회) |

#### 시제 통일 (과거형)

| ❌ 혼용 | ✅ 과거형 통일 |
|--------|--------------|
| 추진하고 있음, 추진 중 | 추진함, 추진 완료 |
| 개선할 예정임 | 개선 추진 ('25.1월~) |

### 4.2.3 문장 길이 가이드

> [!tip] 쉽게 말하면
> **한 줄에 하나의 정보만!** 길어지면 쪼개세요.

| 수준 | 권장 길이 | 예시 |
|------|----------|------|
| **1수준** (요약) | 20~30자 | 윤리경영위원회 4회 개최, 12건 심의 |
| **2수준** (설명) | 30~50자 | 외부전문가 3명 포함 7인 위원회 구성, 분기별 정례회의 운영 |
| **3수준** (상세) | 50~70자 | 청렴문화 확산을 위해 전 직원 청렴교육 12회 실시, 참여율 98% (전년 92% 대비 +6%p) |

### 4.2.4 화살표(→)로 인과관계 표현

> [!tip] 쉽게 말하면
> **"A를 했더니 → B가 됐다"**를 한눈에 보여줍니다.

| 패턴 | 예시 |
|------|------|
| **행동 → 결과** | 심사절차 간소화 → 처리기간 **30% 단축** |
| **투입 → 산출** | 예산 5억 원 투입 → 영화인 **2,000명** 지원 |
| **문제 → 대응** | 민원 증가 → 전담팀 신설로 대응 |
| **기존 → 개선** | 수기 접수(연 500건) → 온라인 전환(연 **2,000건**) |

## 4.3 수치 표현 기법

### 4.3.1 수치 표현 3대 원칙

> [!tip] 쉽게 말하면
> 모든 수치는 **"비교 대상"**과 함께 써야 의미가 있습니다.
> "100건 달성"보다 **"목표 80건 대비 125% 달성(100건)"**이 훨씬 좋습니다.

```
① 정확성: 검증된 수치만 사용 (출처 명시 가능해야 함)
② 일관성: 같은 지표는 같은 단위·기준으로
③ 비교가능성: 목표, 전년, 추세와 반드시 비교
```

### 4.3.2 목표-실적-달성률 표기법

#### 기본 패턴 (인라인)

```
○ (실적현황) '24년 제작지원 실적
   - (목표) 50편 / (실적) 55편 / (달성률) 110%
   - (예산) 200억 원 / (집행) 198억 원 / (집행률) 99%
```

#### 표 형식 (여러 항목)

| 구분 | 목표 | 실적 | 달성률 | 전년비 |
|------|------|------|--------|--------|
| 제작지원 | 50편 | 55편 | **110%** | +5편 ↑ |
| 해외진출 | 30건 | 35건 | **117%** | +10건 ↑ |

#### 달성률별 표현법

| 상황 | 표현 방식 | 예시 |
|------|----------|------|
| **초과달성** | 수치 강조 | 목표(50편) 대비 **110%** 달성(55편) |
| **목표달성** | 달성 명시 | 목표(50편) **100%** 달성 |
| **미달** | 사유+대응 함께 | 목표 대비 85% 달성(42편), 예산 감액 영향 → 하반기 집중 추진 |

### 4.3.3 전년 대비 증감 표기법

#### 증감 기호 사용

| 상황 | 기호 | 예시 |
|------|------|------|
| 증가/상승 | **↑** | 전년 대비 **+15% ↑** |
| 감소/하락 | **↓** | 민원 건수 **30% ↓** |
| 절감/감소(긍정) | **△** | 경비 절감 **△5억 원** |

#### 증감 표기 예시

```
○ (실적) '24년 영화제 초청 실적
   - 국제영화제 초청: 35건 (전년 28건 대비 +7건 ↑, +25%)
   - 수상 실적: 12건 (전년 10건 대비 +2건 ↑)
```

#### 비율 vs 퍼센트포인트

> [!warning] 주의
> **비율의 증감은 '%p'(퍼센트포인트)를 사용합니다.**

| 구분 | 잘못된 표기 | 올바른 표기 |
|------|------------|------------|
| 건수 증감 | - | 전년(100건) 대비 +20건 (+20%) |
| 비율 증감 | 전년 80%에서 +5% 상승 | 전년(80%) 대비 **+5%p** 상승 (85%) |

### 4.3.4 추세 표현 (3~5개년)

> [!tip] 쉽게 말하면
> **"꾸준히 좋아지고 있다"**를 숫자로 보여주세요.

#### 추세표 예시

| 구분 | '21년 | '22년 | '23년 | '24년 | 증감 |
|------|-------|-------|-------|-------|------|
| 지원 편수 | 40편 | 45편 | 50편 | **55편** | +15편 |
| 증가율 | - | +12.5% | +11.1% | +10.0% | 연평균 **+11.2%** |

#### 추세 서술 패턴

```
○ (추세분석) 최근 4개년 실적 추이
   - '21년 40편 → '24년 55편 (4년간 +37.5% 성장)
   - 연평균 성장률 11.2%로 지속 성장세 유지
```

### 4.3.5 단위 표기 기준

| 항목 | 단위 | 표기 예시 |
|------|------|----------|
| 금액 (억 이상) | 억 원 | 1,250억 원 |
| 금액 (억 미만) | 백만 원 | 850백만 원 |
| 인원 | 명 | 150명 |
| 건수 | 건 | 1,200건 |
| 비율 | % | 95.5% |
| 비율 증감 | %p | +3.5%p |
| 영화 편수 | 편 | 50편 |
| 횟수 | 회 | 12회 |

## 4.4 문단 시작 패턴

### 4.4.1 괄호 키워드 패턴

> [!tip] 쉽게 말하면
> 문단 앞에 **(키워드)**를 붙이면 평가위원이 **"아, 이 부분은 이런 내용이구나"** 바로 알 수 있습니다.

```
○ (추진배경) 왜 이 사업을 했는가
○ (추진목표) 무엇을 달성하려 했는가
○ (추진체계) 어떤 조직/시스템으로 했는가
○ (추진실적) 무엇을 얼마나 했는가
○ (추진성과) 어떤 결과/효과가 있었는가
○ (환류계획) 앞으로 어떻게 개선할 것인가
```

### 4.4.2 상황별 키워드 가이드

| 상황 | 추천 키워드 | 용도 |
|------|-----------|------|
| **사업 설명** | 사업개요, 추진배경, 필요성 | 사업을 왜 하는지 설명 |
| **계획 제시** | 추진방향, 추진전략, 추진계획 | 어떻게 할 것인지 설명 |
| **조직 설명** | 추진체계, 추진조직, 협업체계 | 누가 하는지 설명 |
| **활동 설명** | 추진경과, 추진내용, 주요활동 | 무엇을 했는지 설명 |
| **결과 제시** | 추진실적, 실적현황, 주요성과 | 얼마나 했는지/됐는지 설명 |
| **개선 설명** | 개선사항, 환류내용, 향후계획 | 앞으로 어떻게 할지 설명 |

### 4.4.3 지표 서술 기본 흐름

> [!tip] 쉽게 말하면
> 모든 지표는 **"배경 → 체계 → 실적 → 성과 → 환류"** 순서로 쓰면 됩니다.

```
■ [지표명] ─────────────────────────────────────

 ○ (추진배경) 왜 필요한가
    - 환경 변화, 문제 인식
    - 정책 방향, 국정과제 연계

 ○ (추진체계) 어떻게 추진했나
    - 전담조직, 제도, 시스템
    - 추진계획, 목표 설정

 ○ (추진실적) 무엇을 얼마나 했나
    - 정량 실적 (목표-실적-달성률)
    - 주요 활동 내역

 ○ (추진성과) 어떤 결과가 있나
    - 정량 성과 (수치)
    - 정성 성과 (사례, 외부 인정)

 ○ (환류계획) 앞으로 어떻게 할 것인가
    - 문제점 인식, 개선 방향
    - '25년 추진 계획
```

### 4.4.4 실제 작성 예시 (윤리경영)

```
■ 윤리경영 노력과 활동 ────────────────────────────

 ○ (추진체계) 윤리경영 전담조직 운영
    - 감사실 산하 청렴윤리팀 운영 (3명)
    - 윤리경영위원회 구성: 외부위원 3명 포함 총 7명

 ○ (추진실적) '24년 윤리경영 추진 실적
    - (위원회) 윤리경영위원회 4회 개최, 12건 심의
    - (교육) 청렴교육 12회 실시, 전 직원 100% 이수
    - (점검) 부패취약분야 자체점검 2회 실시

 ○ (추진성과) 청렴도 향상 성과 ⭐
    - 종합청렴도 8.52점 → 8.75점 (+0.23점 ↑)
    - 외부청렴도 **1등급** 달성 (전년 2등급)
    - 내부신고 3건 접수 → 전건 조치 완료

 ○ (환류계획) '25년 개선 방향
    - 청렴교육 콘텐츠 다양화 (사례 중심)
    - 자체점검 주기 확대 (연 2회 → 분기별)
```

## 4.5 피해야 할 표현

### 4.5.1 모호한 표현 → 구체적 수치

> [!tip] 쉽게 말하면
> **"다양한", "적극적으로", "많은"** 같은 표현은 **아무 의미가 없습니다.**
> 반드시 **숫자**로 바꾸세요.

| ❌ 피해야 할 표현 | ✅ 권장 표현 |
|-----------------|------------|
| 다수의 영화인 | 영화인 **1,500명** |
| 다양한 사업 | **5개** 사업 |
| 적극적으로 추진 | **12회** 실시, **95%** 집행 |
| 대폭 증가 | **+30%** 증가, **+50건** 증가 |
| ~하는 등 | 구체적으로 나열 (A, B, C 등 3건) |
| 지속적으로 | **연중**, **분기별**, **월 2회** |
| 노력하였음 | **실시함**, **완료함** + 결과 |

### 4.5.2 주관적 평가 → 객관적 근거

> [!tip] 쉽게 말하면
> **"우수한", "성공적인"**은 평가위원이 판단할 몫입니다.
> 우리는 **근거만 제시**하면 됩니다.

| ❌ 주관적 표현 | ✅ 객관적 표현 |
|--------------|--------------|
| 우수한 성과 | 목표 대비 **120%** 달성 |
| 획기적인 개선 | 전년 대비 **50%** 향상 |
| 성공적으로 완료 | 목표 **100%** 달성, 예산 내 완료 |
| 큰 호응을 얻음 | 만족도 **95점**, 참여율 **98%** |
| 좋은 평가를 받음 | 외부평가 **A등급** 획득 |

### 4.5.3 책임 회피 → 원인+대응+성과

> [!tip] 쉽게 말하면
> 목표를 못 달성했을 때 **핑계만 대면 감점**입니다.
> **"왜 못했는지 + 어떻게 대응했는지 + 그래서 뭘 얻었는지"** 다 써야 합니다.

| ❌ 회피 표현 | ✅ 권장 표현 |
|------------|------------|
| ~의 영향으로 미달 | 원인 + 대응조치 + 부분 성과 |
| 불가피하게 축소 | 원인분석 + 대안 추진 + 개선계획 |
| 한계가 있었음 | 제약요인 + 극복 노력 + 향후 계획 |

#### 목표 미달 시 서술 템플릿

```
○ (실적) 목표 100건 대비 85건 달성 (85%)
   - (미달 사유) 기금 감축으로 예산 20% 삭감 ('24.3월)
   - (대응노력) 민간 협력 확대, 하반기 집중 추진
   - (부분성과) 건당 효과성 향상 (수혜인원 +15% ↑)
   - (개선계획) '25년 재원 다각화 추진 (민간펀드 연계)
```

### 4.5.4 불필요한 표현 삭제

| ❌ 불필요한 표현 | ✅ 간결한 표현 |
|----------------|--------------|
| ~에 있어서 | (삭제) |
| ~를 위하여 | ~위해 |
| ~에 대하여 | (삭제 또는 ~에 대해) |
| ~하고자 함 | ~함 |
| 보다 더 나은 | 개선된 |
| 앞으로도 계속하여 | '25년 (구체적 계획) |

## 4.6 성과 부각 기법

### 4.6.1 성과 태그(Tag) 활용

> [!tip] 쉽게 말하면
> 핵심 성과 옆에 **태그**를 붙이면 평가위원 눈에 확 들어옵니다.

| 태그 | 의미 | 사용 상황 |
|------|------|----------|
| **BP** | Best Practice (우수사례) | 타 기관 벤치마킹 가능한 사례 |
| **신규** | 새로 시작한 사업/제도 | 올해 처음 도입한 것 |
| **확대** | 기존 것을 늘림 | 대상, 규모, 범위 확대 |
| **지적사항개선** | 전년 지적사항 해결 | 경영평가 피드백 반영 |
| **최초** | 업계/정부 최초 | 선도적 사례 |

#### 태그 사용 예시

```
○ (추진실적) '24년 주요 추진 사항
   - 장애인 동시관람 서비스 전국 확대 **BP**
   - 중예산영화 제작지원 신설 **신규**
   - 해외진출 지원국 확대 (3개국→5개국) **확대**
   - 지원사업 공모 횟수 확대 (연1회→2회) **지적사항개선**
```

### 4.6.2 Before & After 대조

> [!tip] 쉽게 말하면
> **"예전엔 이랬는데 → 지금은 이렇게 좋아졌다"**를 보여주세요.

```
○ (기존) 서류 기반 수기 접수
   - 연간 처리 500건, 평균 처리기간 14일
   - 신청자 불편, 오류 빈발

○ (개선) 온라인 통합 접수시스템 구축 **신규**
   - 연간 처리 2,000건 (4배 ↑)
   - 평균 처리기간 3일 (78% 단축 ↓)
   - 신청 오류율 0.5% (기존 5% 대비 90% ↓)
```

### 4.6.3 핵심 수치 강조 (Bold)

> [!tip] 쉽게 말하면
> 중요한 숫자는 **굵게** 처리해서 눈에 띄게 하세요.

```
○ (추진성과) 영화인 복지사업 성과
   - 건강검진 지원: **2,500명** (전년 2,000명 대비 +25% ↑)
   - 긴급지원: **150건** 처리, 지원금 **3억 원** 집행
   - 만족도: **94.5점** (전년 91.2점 대비 +3.3점 ↑)
```

### 4.6.4 표로 가독성 높이기

> [!tip] 쉽게 말하면
> 비교할 내용이 많으면 **표**로 정리하세요. 훨씬 읽기 쉽습니다.

#### 연도별 비교 표

| 구분 | '22년 | '23년 | '24년 | 증감 |
|------|-------|-------|-------|------|
| 지원 편수 | 45편 | 50편 | **55편** | +10편 |
| 영화제 초청 | 25건 | 28건 | **35건** | +10건 |
| 만족도 | 88점 | 91점 | **95점** | +7점 |

#### 추진내용-성과 표

| 구분 | 추진 내용 | 성과 |
|------|----------|------|
| **제도개선** | 심사절차 간소화, 공모 횟수 확대 | 처리기간 **30%↓**, 신청 **50%↑** |
| **시스템** | 온라인 접수시스템 구축 | 처리량 **4배↑**, 만족도 **95점** |

## 4.7 전략적 키워드 (Magic Words)

### 4.7.1 경영평가에서 선호하는 표현

> [!tip] 쉽게 말하면
> 공공기관 보고서에서 **자주 쓰이고, 좋은 인상을 주는 단어**들입니다.

| 키워드 | 의미 | 사용 예시 |
|--------|------|----------|
| **고도화** | 수준을 높임 | 시스템 고도화, 서비스 고도화 |
| **내재화** | 조직에 정착시킴 | ESG 가치 내재화, 안전문화 내재화 |
| **선제적** | 미리 대응함 | 리스크 선제적 관리, 선제적 대응 |
| **환류** | 결과를 반영함 | 평가결과 환류, 모니터링 환류 |
| **체계화** | 시스템을 갖춤 | 지원체계 체계화, 교육 체계화 |
| **다각화** | 방법을 다양하게 | 재원 다각화, 채널 다각화 |
| **사각지대** | 소외된 영역 | 복지 사각지대 해소, 안전 사각지대 발굴 |
| **실효성** | 실제 효과 | 제도 실효성 제고, 실효성 있는 지원 |

### 4.7.2 영진위 특화 표현

| 상황 | 추천 표현 |
|------|----------|
| 영화인 지원 확대 | "영화인 복지 사각지대 해소", "현장 밀착형 지원" |
| 기금 위기 대응 | "재원 다각화", "선택과 집중", "효율적 재원 배분" |
| 데이터 개방 | "수요자 맞춤형 개방", "민간 활용도 제고" |
| AI 활용 | "AI 기반 업무혁신", "디지털 전환 가속화" |

## 4.8 자주 하는 실수

### 4.8.1 피해야 할 실수 TOP 5

| 순위 | 실수 | 문제점 | 해결책 |
|------|------|--------|--------|
| 1 | 수치 없이 "노력함"만 작성 | 성과 증명 불가 | 모든 활동에 숫자 붙이기 |
| 2 | 전년 비교 없이 실적만 나열 | 개선 여부 불명확 | 전년/목표 대비 비교 필수 |
| 3 | 서술식으로 장황하게 작성 | 핵심 파악 어려움 | 개조식으로 전환 |
| 4 | "우수한", "성공적" 등 자화자찬 | 객관성 결여 | 수치/외부평가로 대체 |
| 5 | 미달 시 핑계만 나열 | 노력 부재로 인식 | 대응+성과+개선계획 함께 |

### 4.8.2 수치 표기 오류

| ❌ 잘못된 표기 | ✅ 올바른 표기 | 이유 |
|--------------|--------------|------|
| 80%에서 85%로 5% 상승 | 80%에서 85%로 **5%p** 상승 | 비율 증감은 %p |
| 100건에서 120건으로 120% 증가 | 100건에서 120건으로 **20%** 증가 | 증가율 계산 오류 |
| 50억원 | **50억 원** | 단위 띄어쓰기 |

## 4.9 작성 체크리스트

### 문장별 체크

- [ ] 50자 이내인가?
- [ ] 피동태가 아닌 능동태인가?
- [ ] 수치가 포함되어 있는가?
- [ ] "다양한", "적극적" 같은 모호한 표현이 없는가?

### 문단별 체크

- [ ] (키워드) 괄호로 시작하는가?
- [ ] 기호 체계(○, -, ·)를 지켰는가?
- [ ] 목표-실적-달성률이 함께 있는가?
- [ ] 전년 대비 증감이 표시되어 있는가?

### 지표별 체크

- [ ] 배경→체계→실적→성과→환류 순서인가?
- [ ] 핵심 성과에 태그(BP, 신규 등)를 붙였는가?
- [ ] 표나 도식을 활용했는가?
- [ ] 중요 수치를 Bold 처리했는가?

## 핵심 정리

> [!summary] 제4장 핵심 정리
>
> **1. 개조식 = 기본**
> - ■ → ○ → - → · 기호 체계 준수
> - 한 항목에 한 가지 내용만
>
> **2. 문장 4대 원칙**
> - 간결(50자), 명확(모호함 제거), 객관(수치), 구체(누가·무엇·얼마나)
>
> **3. 수치 표현 = 비교와 함께**
> - 목표-실적-달성률 병기
> - 전년 대비 증감 필수 (↑, ↓, %p)
>
> **4. 문단 시작 = (키워드)**
> - (추진배경), (추진체계), (추진실적), (추진성과), (환류계획)
>
> **5. 성과 부각**
> - 태그: BP, 신규, 확대, 지적사항개선
> - Bold로 핵심 수치 강조
> - Before & After 대조
>
> **6. 절대 쓰지 말 것**
> - "다양한", "적극적으로", "노력함"
> - "우수한", "성공적인" (자화자찬)
> - "~의 영향으로" (핑계)
