## 📋 계량지표 상세 정의

### 2-1 한국영화 제작·유통 활성화

#### (1) 한국영화 기획·제작 활성화 (5점)

| 항목 | 내용 |
|------|------|
| **정의** | 한국영화 기획개발 및 제작지원을 통한 안정적 창작환경 조성 및 창작 활성화 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 5개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 5개년) |

**측정산식**
```
기획·제작 활성화 성과 = 제작지원작 온라인 관람건수 / 한국 독립·예술영화 온라인 관람건수
```

| 변수 | 설명 |
|------|------|
| 온라인 관람건수 | 《한국영화산업 결산보고서》 기준 IPTV 및 디지털케이블 업체 대상 산정 |
| 근거자료 | 영화관입장권통합전산망 |

---

#### (2) 지원작품 영화제 초청 성과 (5점)

| 항목 | 내용 |
|------|------|
| **정의** | 영화제작지원 작품의 국내외 유수 영화제 초청 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 5개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 5개년) |

**측정산식**
```
영화제 초청 성과 = 지원작품의 국내외 유수 영화제 초청 실적
```

| 변수 | 설명 |
|------|------|
| **국내 영화제** | 부산, 전주, DMZ, 서울여성, 부천, 제천, 서울독립영화제 |
| **국외 영화제** | '국제영화제 참가활동지원' 사업 지원대상 영화제 (C급 이상) |
| 근거자료 | 영화관입장권통합전산망, KoBiz 웹사이트 |

### 2-2 한국영화의 혁신성장 기반 강화

#### 비계량 평가 (9점)

| 항목 | 내용 |
|------|------|
| **정의** | 한국영화 혁신성장 기반 강화 사업의 추진계획 및 집행효율성, 체계적 성과와 환류과정을 평가 |
| **평가대상 사업** | (1) 국제교류 및 동반성장<br>(2) 온라인시장 활성화<br>(3) 공정환경 조성 및 영화정책 연구 |

---

#### (1) 한국영화 국제교류 지원 성과 (4점)

| 항목 | 내용 |
|------|------|
| **정의** | 기관이 참가 지원하는 플랫폼에서의 한국 영화 및 기술의 국제교류 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 5개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 5개년) |

**측정산식**
```
국제교류 지원 성과 = 해외수출 상담건수/지원예산 (50%) + 해외수출 계약건수/지원예산 (50%)
```

| 변수 | 설명 |
|------|------|
| 상담·계약건수 | 기관이 참가·지원하는 플랫폼에서의 한국영화 판권 및 영화기술 상담·계약 건수 |
| 판권계약 | 영화와 관련된 권리(상영, 배급, 리메이크 등)의 계약 |
| 영화기술계약 | 영화제작 기술 및 기술장비 등의 수출계약 |
| 지원예산 | 당해연도 해외수출 지원사업의 예산 |
| 근거자료 | 문화체육관광부 보고 사업실적보고서 |

---

#### (2) 영화분야 공공데이터 개방 성과 (5점)

| 항목 | 내용 |
|------|------|
| **정의** | 기관의 영화분야 공공데이터 개방 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 5개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 5개년) |

**측정산식**
```
공공데이터 개방 성과 = 영화분야 공공데이터 개방건수 / 당해연도 개봉편수
```

| 변수 | 설명 |
|------|------|
| 공공데이터 개방건수 | 영화관입장권통합전산망 영화분야 DB(박스오피스, 영화정보, 영화인, 영화사)를 통해 오픈API 형식으로 제공되는 공공데이터 건수 |
| 당해연도 개봉편수 | '실질개봉작' 기준 (연간 40회차, 최소 1개관에서 7일간 전일 상영되는 경우의 상영회차 적용) |
| 근거자료 | 《한국영화산업 결산보고서》 |

### 2-3 영화문화의 가치확산

#### (1) 문화소외계층 관람환경 개선 (4점)

| 항목 | 내용 |
|------|------|
| **정의** | 가치봄 영화 관람 확대를 통한 국민의 차별 없는 영화문화 향유 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 5개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 5개년) |

**측정산식**
```
문화소외계층 관람환경 개선 성과 = 가치봄 영화 신규제작 편수 / 제작예산
```

| 변수 | 설명 |
|------|------|
| 가치봄 영화 신규제작 편수 | 문화체육관광부 보고 사업실적보고서 기준 |
| 제작예산 | 장애인 관람환경 개선사업의 당해연도 가치봄 제작지원 예산 (한글자막, 화면해설 및 DCP/VOD 제작비) |

---

#### (2) 지역 영화문화 향유권 강화 성과 (2점)

| 항목 | 내용 |
|------|------|
| **정의** | 작은영화관, 찾아가는 영화관 사업의 활동 실적을 활용하여 지역 영화문화 향유권 강화를 위한 기관의 노력과 성과를 평가 (상향지표) |
| **기준치** | 전년도 실적과 직전 3개년 평균 실적 중 높은 실적 |
| **최고목표** | 기준치 + 1.5 × 표준편차 (과거 3개년) |
| **최저목표** | 기준치 - 2 × 표준편차 (과거 3개년) |

**측정산식**
```
지역 영화문화 향유권 강화 성과 = 작은영화관 관객수 + 찾아가는 영화관 관객수
```

| 변수 | 설명 |
|------|------|
| 관객수 | 당해연도 '작은영화관 기획전 상영지원사업' 및 '찾아가는 영화관 운영지원사업'의 영화상영 프로그램에 참여한 총 관객수 |

> [!note] 참고
> 코로나19 상황으로 인한 '20년 찾아가는 영화관 사업 무기한 연기 및 취소, 개최 축소 등으로 과거 실적 데이터의 연속성이 부재하여 '19년~'20년 데이터를 제외한 **과거 3개년 실적**을 기준으로 목표부여(편차) 방식으로 평가
