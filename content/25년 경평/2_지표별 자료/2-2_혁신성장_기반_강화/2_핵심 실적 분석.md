## 1. 영화산업 표준보수지침 제정

### 추진배경

| 환경분석 | 개선과제 |
|---------|---------|
| 영화산업 근로자 처우 개선 필요 | 표준보수 기준 마련 |
| 2015년 법개정 이후 10년간 지침 부재 | 노사정 합의 도출 |
| 영화산업 근로환경 불안정 | 제작지원 사업요강 연계 |

### 추진실적

| 구분 | 내용 |
|------|------|
| 합의 도출 | **노사정 4자 합의** (영진위, 전국영화산업노동조합, 한국영화제작가협회, 한국영화프로듀서조합) |
| 공표 | 2025.10.01. 문체부 공식 공표 |
| 법적 근거 | 영화 및 비디오물의 진흥에 관한 법률 |

**사업요강 연계**
| 연계사업 | 내용 |
|---------|------|
| 중예산 한국영화 제작지원사업 | 2026년 사업요강 내 표준보수액 **의무조항 반영 완료** |

| 성과 | 내용 |
|------|------|

| 근로환경 개선 | 영화산업 근로자 처우 개선 기반 마련 |

## 2. 영화산업 안전보건체계 구축

### 추진배경

| 환경분석 | 개선과제 |
|---------|---------|
| 영화 촬영현장 안전사고 위험 | 안전보건 협의체계 구축 |
| 중대재해처벌법 시행 | 산업단위 안전관리 체계 필요 |
| 「영화산업 안전보건체계 구축방안 연구」 완료 | 우선 이행과제 확인 |

### 추진실적

**추진 과정**

| 단계 | 내용 |
|------|------|
| [1단계] 사전준비 | 「영화산업 안전보건체계 구축방안 연구」 확인 → 우선 이행과제 도출 |
| [2단계] 추진과정 | 노사정 실무 협의회 개최 (4월 국회 방문 → 5월 결과공유 → 10월 협의회 구축 협의) |
| [3단계] 실행결과 | **안전보건협의회 구성을 위한 노사정 공동협약서 체결** (2025.11.20.) |

**협약 참여기관**
- 문화체육관광부 영상콘텐츠산업과
- (사)한국영화제작가협회
- (사)한국영화프로듀서조합
- 전국영화산업노동조합
- (사)한국독립영화협회
- 영화진흥위원회

### 추진성과

| 성과 | 내용 |
|------|------|
| 산업단위 최초 | 영화산업 **최초** 안전보건 관련 노사정 공동협약 체결 |
| 사업요강 반영 | 2026년 중예산 사업요강 **영화산업 안전관리비 편성 의무화** 반영 |
| 후속 조치 | 명예산업안전감독관 제도 2026년 시범 시행 협의 진행 |

## 3. 영화인신문고 운영 고도화

### 추진배경

| 환경분석 | 개선과제 |
|---------|---------|
| 저작권 분쟁 증가 | 저작권 전문 중재 체계 필요 |
| 비노동분쟁 사건 처리 어려움 | 중재위원회 신설 |
| 분쟁해결 전문성 강화 요구 | 3심제 도입 |

### 추진실적

**저작권파트 중재위원회 신설**

| 항목 | 내용 |
|------|------|
| 위원 구성 | 저작권 단체 추천 2인 + 제작자 단체 추천 2인 + 영진위 추천 1인 = **총 7인** |
| 전문위원 | 작가 및 제작사 측 각 1인으로 **공평성 제고** |
| 회의 개최 | **총 11회** 진행 (2025.11.21. 기준) |
| 분쟁해결 체계 | **3심제 마련** → 중재 양 당사자의 이의신청 권리 보장 |

**2025년 운영 실적** (11월 기준)

| 구분 | 신고접수 | 종결건수 | 종결비율 |
|------|:-------:|:-------:|:-------:|
| 2025년 | 110건 | 72건 | 65% |
| 누적 ('04~'25년) | 1,738건 | 1,585건 | 91.2% |

### 추진성과

| 성과 | 내용 |
|------|------|
| 중재위원회 신설 | 저작권파트 중재위원회 **신규 신설** |
| 3심제 도입 | 분쟁해결 전문성 및 공정성 강화 |
| 누적 종결비율 | **91.2%** (1,585건/1,738건) |
