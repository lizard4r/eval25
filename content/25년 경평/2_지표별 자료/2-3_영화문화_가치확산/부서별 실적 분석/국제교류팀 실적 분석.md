## 📊 주요 실적

### 1. 국제영화제 참가활동 지원 ⭐

#### 1-1. 지원 현황

| 구분 | 2024년 | 2025년 | 증감 |
|------|:------:|:------:|:----:|
| 지원작 | 68편 | **75편** | +10.29% |
| 영화제 | 40개 | 38개 | - |
| 수상 실적 | - | **12건 수상** | - |

#### 1-2. 영화문화 가치확산 연계 효과

| 구분 | 내용 |
|------|------|
| **문화 확산** | 38개 국제영화제 한국영화 상영 → 글로벌 관객 접점 확대 |
| **위상 제고** | 12건 수상 → 한국영화 문화적 가치 국제 인정 |
| **다양성 확산** | 독립예술영화 포함 다양한 작품 해외 소개 |

---

### 2. <어쩔수가없다> 아카데미 프로모션 ⭐

#### 2-1. 국제영화제 수상/초청 성과

| 영화제 | 수상/초청 |
|--------|----------|
| **토론토국제영화제** | **국제관객상** 수상 |
| **시체스영화제** | **감독상** 수상 |
| **마이애미국제영화제** | **공로상** |
| **뉴포트비치영화제** | **글로벌임팩트상** |
| **고담어워즈** | 후보 지명 |
| **아카데미 국제장편상** | 유력 후보 거론 (Indiewire, Hollywood Reporter) |

> 🏆 **핵심성과**: 아카데미 국제장편상 유력 후보 → 한국영화 문화적 위상 최고조

#### 2-2. 영화문화 가치확산 연계 효과

| 구분 | 내용 |
|------|------|
| **글로벌 인지도** | 주요 국제영화제 4관왕 → 세계적 관심 집중 |
| **문화 외교** | 한국영화=고품질 문화콘텐츠 인식 확산 |
| **후속 효과** | 한국영화 전반에 대한 국제적 관심 상승 |

---

|------|------|
