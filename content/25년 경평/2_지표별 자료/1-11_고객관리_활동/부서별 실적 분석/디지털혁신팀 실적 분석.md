## 📊 세부평가내용① 연계 - 고객 정의와 관리전략

### 가. 디지털혁신팀 고객 정의

| 고객 유형 | 정의 | 관리 채널 |
|---------|------|---------|
| **영화인** | KOBIS 영화인 DB 등록·가입자 | 영화인 작품참여내역서 서비스 |
| **영화산업 관계자** | 투배사, 제작사, 극장, OTT 등 | 전송사업자 연동, 데이터 연계 |
| **일반 이용자** | KOBIS 웹/모바일 방문자 | 홈페이지, OPEN-API |
| **연구자·언론** | 영화산업 통계 활용자 | 박스오피스, 통계 데이터 |
| **유관기관** | 콘진원, 저작권위원회 등 | 데이터 연계 API |

### 나. 고객별 관리전략

| 고객 유형 | 관리전략 | 서비스 |
|---------|---------|--------|
| **영화인** | 경력정보 접근성 향상 | 작품참여내역서, 영화정보통합관리창구 |
| **영화산업 관계자** | 데이터 연동 안정성 | 실시간 박스오피스, 전송사업자 지원 |
| **일반 이용자** | 정보 접근 편의성 | 웹/모바일 서비스, OPEN-API |
| **유관기관** | 데이터 연계 확대 | 기관 전용 API |

## 📊 고객 편의성 향상 실적

### 가. 「영화정보통합관리창구」 신설 ('25.12.)

#### 1) 개선 효과

| AS-IS (기존) | TO-BE (개선) |
|-------------|-------------|
| 단일 '정보수정요청' 창구 | **4개 전용 창구** 분리 운영 |
| 전화문의 과다, 등록 지연 | **신청 오류율 감축** |
| 프로세스·양식 부재 | **등록 소요시간 단축** |

#### 2) 신규 창구 서비스

| 창구 | 서비스 내용 |
|------|-----------|
| FIMS 영화코드 신청 | 신규 영화정보 등록(영화코드 발급) |
| 상영타입 추가신청 | 3D, 4D, IMAX 등 상영타입 추가 |
| 크레디트 파일 제출 | 한국영화 참여인력 정보 등록 |
| 정보수정요청 | 영화·영화인·업체·영화제 정보 수정 |

> 🎯 **영화인 이용 편의성 향상 → 고객만족도 제고**

### 나. 영등위 연계를 통한 이중행정 해소

| 기존 | 개선 |
|------|------|
| 영진위 필증 발급 → 영등위 필증 제출 | **API 연계로 제출서류 간소화** |
| 영화인 이중 행정 불편 | **원스톱 서비스** |

### 다. 대표홈페이지 개선

| 시기 | 개선내용 | 효과 |
|------|---------|------|
| 2025.2.24. | 국민제안/묻고답하기 개인정보 비공개 | 이용자 보호 |
| 2025.4.7. | 지원사업 접수 마감 기능 개선 | 사업접수 혼선 최소화 |
| 2025.9.10. | 한국영화성평등센터 안내페이지 생성 | 정보 접근성 향상 |
| 2025.11.10. | 대표번호 운영시간 표기 | 고객 편의 향상 |
