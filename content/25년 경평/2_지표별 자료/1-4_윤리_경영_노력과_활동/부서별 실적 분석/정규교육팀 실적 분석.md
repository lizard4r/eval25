> **분석대상**: 2025년도 부서 성과평가 실적보고서 (아카데미-정규교육팀)  
> **제출일**: 2025. 11. 28.  
> **작성목적**: 한국영화아카데미(KAFA) 인권경영·윤리경영 관련 실적 발굴

## 📋 지표 개요

### 가. 세부평가내용 (편람 기준)

| 평가요소 | 세부내용 |
|---------|---------|
| **① 윤리경영체계 구축·운영** | 윤리경영 관련 전담조직, 지침 마련·운영, 반부패·청렴교육 실적 등 |
| **② 성희롱·성폭력 예방 및 근절** | 예방지침 개정, 고충상담원 전문교육, 예방교육 참여율, 상시대응체계 구축 |
| **③ 이해충돌방지법 이행** | 이해충돌방지법에 따른 이해충돌 방지 노력과 성과 |
| **④ 인권존중 노력과 활동** | 인권교육, 인권침해 구제절차, 대내외 이해관계자 인권보호 |

| 연계항목 | 연계내용 |
|---------|---------|
| **인권경영** | 영화 실습 제작현장 인권 보호, 인터미시 코디네이터 도입 |
| **성희롱·성폭력 예방** | 교육생·제작스태프 대상 예방교육, 고충처리제도 운영 |
| **안전교육** | 촬영현장 안전사고 예방 교육 |

## 📊 세부평가요소④ 인권존중 노력과 활동 연계 실적 ⭐ BP

### 가. 인터미시(Intimacy) 코디네이터 현장 적용 ⭐ 국내 최초

| 구분 | 내용 |
|------|------|
| **추진배경** | 영화·영상 산업에서 배우와 스태프의 인권 보호 및 안전한 촬영환경 조성이 핵심 과제로 부상하였으나 국내에서는 관련 전문인력, 표준화된 교육 및 현장 참여가 부족한 상황 |
| **사전조치** | 2024년 KAFA에서 국내 최초로 일본 전문가 초청 교육 진행 → 한국 PD가 전문 교육 수료 후 **국내 최초 인터미시 코디네이터** 자격 취득 |
| **추진노력** | 국내 1호 인터미시 코디네이터를 통한 교육 및 현장 지원 |
| | • 인터미시 장면 개념, 사례(보호장비 종류·사용방법, 사전협의서 가이드라인 등) 교육 |
| | • 현장에서의 역할에 대한 교육 |
| | • 실습작품 촬영 전 사전교육 |
| | • 촬영현장 코디네이터 운용하여 교육생 보호 및 실습촬영 체계적 관리 |
| **현장적용** | 글로벌과정 실습작품 <몽고반점> (연출: 저스틴지, PD: 윤세령) 9.1.(월)~9.2.(화) 현장지원 |
| **추진성과** | • **국내 최초** 인터미시 코디네이터 촬영 현장 적용 |
| | • 신체노출 등 민감한 장면 촬영 시 **인권 침해 요소 방지** |
| | • 안전한 환경에서 촬영 진행 |
| | • **안전·인권 중심 제작문화 확산 촉진 계기 마련** |

> 🏆 **BP 사례**: 공공 영화교육기관으로서 학생 창작자 및 스태프의 인권 보호 체계 마련과 **안전한 제작문화 확산**을 위한 선도적 역할 수행
