# 상생협력 및 지역발전 - 부서성과평가 자료 분석

> **제출일**: 2025. 11. 28.  
> **작성목적**: 상생협력, 지역사회 참여, 문화예술 저변확대 관련 지표 연계 내용 발굴

## 📊 세부평가내용① 연계 - 중소기업·사회적경제기업 상생협력

### 가. 독립영화계 협치 구조 운영

| 구분 | 내용 |
|------|------|
| **독립예술영화소위원회** | 독립영화계 협치 및 지원사업 정책·현안 논의 |
| **다큐멘터리 TF** | 다큐멘터리 단체, 학계, 영화제, PD 등 전문가 5인 구성 |

> ✅ **독립영화계와의 협치를 통한 사업 개선** - 소위원회 5회, TF 6회 개최

### 나. 중소 제작사 지원 강화

#### 1) 기획개발지원의 중소 제작사 지원

| 사업 | 지원대상 | 지원규모 |
|------|---------|---------|
| **초기기획** | 중소 제작사 기획개발비 지원 | 50편 / 1,000백만 원 |
| **영화화** | 역량 있는 중소 제작사 패키징 지원 | 15편 / 765백만 원 |
| **차기작 기획개발지원** **(신규 '26년)** | 우수 제작사 차기작 기획개발비 | 1,650백만 원 |
| **IP 라인업 개발지원** **(신규 '26년)** | 중소 독립 제작사 IP 중심 개발비 | 1,000백만 원 |

> 💡 **코로나 이후 기획개발 자금 조달 여력이 없는 중소 독립 제작사** 중심 지원 확대

#### 2) '26년 사업 개선: 중소제작사 자율적 기획개발 환경 보장

| 주요 변경 | 내용 | 기대효과 |
|---------|------|---------|
| **예산 확보** | 62.8억 원 (전년대비 141.1%↑) | 신규·우수 IP 대량 생산 |
| **차기작 부활** | '23년 폐지된 차기작사업 보완·개선 | 역량 있는 제작사 자율적 개발 |
| **IP 라인업 신설** | 중소 독립 제작사 IP 중심 지원 | 산업 선순환 유도 |
| **순환구조 마련** | 수익 발생시 지원금 일부 회수 | 재원 선순환 |

### 나. 독립예술영화 제작사 지원

#### 1) 인큐베이팅 지원사업

| 구분 | 내용 |
|------|------|
| **대상** | 경력자 및 장편 연출 경력 없는 신인 연출자 |

## 📊 세부평가내용④ 연계 - 문화예술 저변확대

### 가. 영화 창작 생태계 지원

#### 1) 기획개발 단계 창작 지원 체계

```
┌─────────────────────────────────────────────────────────────────┐
│  창작 기반 조성                                                  │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐           │
│  │ 시나리오      │  │ 작가부문     │  │ 초기기획     │           │
│  │ 공모전        │→ │ 1·2단계      │→ │ 제작사 부문  │           │
│  │ (신인 발굴)   │  │ 성장지원     │  │ (기획개발비) │           │
│  └──────────────┘  └──────────────┘  └──────────────┘           │
│          ↓                 ↓                 ↓                   │
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │                    영화화 / 제작지원                         │ │
│  │         → 민간투자 연계 → 극장 개봉 → 관객 확보             │ │
│  └─────────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
```

#### 2) S#1 센터 창작 허브 기능 강화

|--------|------|------|
| **S#1 해피아워** | 월별 주제 선정, 창작자-산업 교류 | 5회 진행, **271명** 참석 |
| **S#1 비즈워크** | 작가-산업 연계 매칭 행사 | 3회 진행, **427건** 미팅 |
| **S#1의 밤** | 창작자-산업 간 네트워킹 연회 | **163명** 참석 |
