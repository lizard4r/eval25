## 📊 세부평가요소② 규제혁신 - 프로세스 개선

### 가. 독립예술영화 개봉지원 프로세스 혁신

| 구분 | 개선 전 | 개선 후 |
|------|---------|---------|
| 공모횟수 | 연 1회 | **연 2회** |
| 개봉기한 | 11월 | **12월** |
| 조기공모 | - | **전년도 12월** 실시 |
| 약정체결 | '24년 7월 | **'25년 2월(상반기), 7월(하반기)** |
| 자기부담금 | 있음 | **폐지** |

> 🎯 **효과**: 심사기간 단축 + 보조사업자 부담 경감 + 사업 수행기간 확보

### 나. 국민 영화관람 할인권 배포방식 혁신 ⭐ BP

| 구분 | 1차 배포 | 2차 배포 (개선) |
|------|---------|---------------|
| 배포방식 | 선착순 다운로드 | **자동 지급** (다운로드 불필요) |
| 시스템 장애 | 장기간 접속 장애 | **장애 ZERO** |
| 민원 | 7건 | **ZERO** |
| 일별 소진량 | 기준 | **+37.5%** 증가 |

## 📊 세부평가요소③ 국민 참여 - 협업 확대

### 가. 한국노인인력개발원 협업 ⭐ 신규

| 구분 | 내용 |
|------|------|
| **사업명** | 배리어프리 문화동행 시범 사업 |
| **혁신성** | 노인일자리 창출 + 동시관람 장비 관리 안정화 동시 달성 |
| **성과** | 보건복지부 전국화 심사 통과 ('25.9월) |
| **확산** | '26년 이후 전국 점진 확대 예정 |

### 나. 영화제·기관 협업 확대

| 협업유형 | 협업대상 | 실적 |
|---------|---------|:----:|
| 영화제 협업 | 국내 영화제 10개 | **30여편** 가치봄 상영 |
| IPTV 협업 | Btv, 지니tv | **22편** 편성 |
| 온라인 협업 | 인디그라운드 | **20편** 편성 |
| 배급사 협업 | 결합형 동시개봉작 무대인사 | **6회차** 편성 |

### 다. 현장 소통 강화

| 구분 | 추진내용 | 효과 |
|------|---------|------|
| 전용관 전수 방문 | 전국 전용관 27개관 찾아가는 현장 점검·간담회 | 고객만족도 향상 기여 |
| 사업별 간담회 | 독립예술영화 개봉지원 간담회 2회, 지원소위 의견수렴 3회 | 2026년도 사업 개선 반영 |
| 영화제 관계자 간담회 | 총 30여명 대상 2회 | 영화제 지원 구분·평가지표 개선 |
