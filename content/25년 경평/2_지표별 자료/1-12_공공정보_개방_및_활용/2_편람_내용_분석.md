# (3) 공공정보 개방 및 활용

## 1. 세부평가 요소 ① - 공공정보 개방

### 가. 평가요소
공공정보 개방을 위한 기관의 노력과 성과는 적절한가? (공공저작물 개방실적 및 관리노력, 사전정보공표 실적, 정보공개 실적 등)

### 나. 작성 필요 내용

#### 1) 공공저작물 개방 (공공누리)
- 공공누리 적용 현황
- 저작물 유형별 개방 실적
- 공공저작물 DB 구축
- 공공저작물 카탈로그 정비

#### 2) 공공누리 유형별 개방
- 제1유형: 출처표시 (자유이용)
- 제2유형: 출처표시+상업적 이용금지
- 제3유형: 출처표시+변경금지
- 제4유형: 출처표시+상업적이용금지+변경금지

#### 3) 공공저작물 관리
- 공공저작물 목록 관리
- 개방 가능 저작물 발굴
- 개방 확대 노력
- 이용 활성화 지원

#### 4) 사전정보공표
- 사전정보공표 목록 작성
- 주기적 공표 실적
- 공표 내용의 충실성
- 공표 정보 최신성 유지

#### 5) 정보공개
- 정보공개 청구 접수 및 처리
- 정보공개 처리 기한 준수
- 공개율 (전부공개·부분공개)
- 비공개 사유의 적정성

#### 6) 정보공개 청구 대응
- 신속한 처리
- 친절한 안내
- 비공개 결정 시 상세한 사유 제공
- 이의신청 처리

### 다. 작성 시 강조할 점
- 공공누리 개방 실적 확대
- 영화 통계·정보의 적극적 개방
- 사전정보공표 충실 이행
- 정보공개 청구 신속 처리

## 2. 세부평가 요소 ② - 데이터 개방 및 활용

### 나. 작성 필요 내용

- 개방 데이터셋 수

#### 2) 영화산업 통계 데이터 개방

#### 3) 데이터 품질 관리
- 데이터 정확성
- 최신성 유지
- 완결성 확보
- 일관성 유지

#### 4) 데이터 활용 촉진
- API 제공

- 데이터 활용 가이드

#### 5) 데이터 기반 서비스
- 통계 정보 제공 서비스
- 실시간 데이터 제공

### 다. 작성 시 강조할 점
- KOBIS를 통한 실시간 박스오피스 데이터 제공
- 영화산업 통계 DB 구축 및 개방

- 평가 준비 체계
- 취약 부문 개선
- 우수 부문 유지
- 사전 모의평가

#### 3) 정보화 수준 향상
- 정보시스템 고도화
- 정보보안 강화
- 서비스 개선
- 이용자 만족도 제고

### 다. 작성 시 강조할 점
- 문화정보화 수준평가 우수 등급
- 전년 대비 점수 향상
- 정보화 사업 성과
- 정보보안 체계 강화
