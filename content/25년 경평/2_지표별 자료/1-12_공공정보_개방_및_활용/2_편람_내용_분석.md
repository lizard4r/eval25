# [1-12] 공공정보 개방 및 활용

> [!abstract] 지표 개요
> - **평가 범주**: 경영관리 > 국민소통
> - **배점**: **비계량 1점** + **계량 1점** (문화정보화수준평가)
> - **지표정의**: 정보공개, 데이터 개방, 정보공유, 수요자 맞춤형 서비스 제공 등 공공정보 개방 및 활용을 위한 노력과 성과를 평가

---

## 1. 비계량 지표 (1점)

### 가. 세부평가내용

**공공정보 개방 노력**
- 공공저작물(공공누리) 개방 실적 및 관리 노력
- 사전정보공표 실적
- 정보공개 실적 등

### 나. 작성 필요 내용

#### 1) 공공저작물 개방 (공공누리)

| 구분 | 작성 내용 |
|------|---------|
| **공공누리 적용** | 공공누리 적용 저작물 수, 유형별(1~4유형) 현황 |
| **저작물 개방** | 개방 가능 저작물 발굴 및 등록 실적 |
| **DB 구축** | 공공저작물 목록 관리, 카탈로그 정비 |
| **이용 활성화** | 개방 저작물 활용 지원 활동 |

#### 2) 사전정보공표

| 구분 | 작성 내용 |
|------|---------|
| **공표 항목** | 사전정보공표 목록 작성 및 관리 |
| **공표 실적** | 항목별 공표 건수 및 주기 |
| **충실성** | 공표 내용의 정확성, 최신성 |
| **선제 공개** | 국민 관심 정보의 선제적 공개 노력 |

#### 3) 정보공개

| 구분 | 작성 내용 |
|------|---------|
| **청구 처리** | 정보공개 청구 접수 및 처리 현황 |
| **처리 기한** | 정보공개 처리 기한 준수율 |
| **공개율** | 전부공개·부분공개 비율 |
| **비공개 사유** | 비공개 결정 시 사유의 적정성 |

### 다. 작성 시 강조할 점

> [!tip] 영화진흥위원회 특화 포인트
> - 📌 **KOBIS 데이터 개방**: 영화 통계, 박스오피스, 영화인 정보 등 적극 개방
> - 📌 **공공데이터포털 등록**: data.go.kr 등록 및 활용도 제고
> - 📌 **영화 정책 정보 공개**: 지원사업 결과, 정책 자료 등 사전 공개
> - 📌 **정보공개 거부 최소화**: 명확한 사유 제시, 부분공개 확대

---

## 2. 계량 지표 (1점) - 문화정보화 수준평가

### 가. 세부평가내용

**평가 방식**
- 문화체육관광부(정보화담당관) 실시 **문화정보화 수준평가** 결과 환산
- 최종점수(100점 만점) → 1점으로 환산
- 기준점수: 90 (전년도 90 이상 시 전년도 결과 사용)

### 나. 평가 영역

| 평가 영역 | 주요 내용 |
|---------|---------|
| **정보화 전략** | 정보화 계획 수립 및 이행 |
| **정보시스템 운영** | 시스템 안정성, 가용성 |
| **정보보호** | 정보보안 체계, 개인정보보호 |
| **정보화 성과** | 대국민 서비스 수준, 데이터 개방 |

### 다. 대비 전략

> [!important] 외부 평가 대응
> - **문체부 평가 일정** 사전 확인
> - **전년도 지적사항** 개선 완료
> - **정보보호 체계** 점검 및 강화
> - **IT 시스템 안정성** 확보

## 3. 증빙자료 준비사항

### 가. 필수 제출 자료

| 구분 | 증빙자료 |
|------|---------|
| 공공누리 | 공공누리 적용 현황, 저작물 목록 |
| 사전정보공표 | 사전정보공표 목록 및 실적 |
| 정보공개 | 정보공개 청구 처리 현황 |
| 공공데이터 | 공공데이터포털 등록 현황, 데이터셋 목록 |
| 문화정보화 | 문화정보화 수준평가 결과 |

### 나. 정량지표 준비

| 지표 | 내용 |
|------|------|
| 공공누리 적용 | 저작물 수, 유형별 분포 |
| 사전정보공표 | 항목 수, 갱신 주기 |
| 정보공개 | 청구 건수, 공개율, 처리기한 준수율 |
| 공공데이터 | 데이터셋 수, API 제공 건수, 활용 건수 |
| 홈페이지 | 방문자 수, 만족도 |
