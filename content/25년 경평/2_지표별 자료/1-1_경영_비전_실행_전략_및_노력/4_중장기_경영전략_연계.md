## 📋 중장기 경영전략체계 개요

### 가. 가치체계

| 구분       | 내용                                   |
| -------- | ------------------------------------ |
| **미션**   | 한국영화 진흥으로 국민 문화생활 향상에 기여             |
| **비전**   | K-무비의 변화와 도약을 함께하는 파트너               |
| **핵심가치** | 성장과 균형 \| 도전과 성과 \| 공정과 확산 \| 책임과 신뢰 |

### 나. 2029 경영목표

| 경영목표              | 의미                                   |
| ----------------- | ------------------------------------ |
| K-무비의 지속 성장 기반 강화 | 창제작인력 양성, 독립예술영화 지원, 신기술 기반 환경조성     |
| K-무비의 국내외 경쟁력 극대화 | R&D(기획개발), 중예산영화 지원, IP기반 글로벌 경쟁력 육성 |
| 영화산업 선순환 구조 확보    | 공정 상생 환경 조성, 관람환경 개선, 관객층 확대         |
| 책임과 합리적 조직경영 실현   | 성과중심 공공경영 의식 향상, 신뢰 회복               |

### 다. 4대 전략방향 및 12대 전략과제

| 전략방향               | 전략과제                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| **I. K-무비 기반강화**   | ① K-무비 창제작인력 양성 및 지원 강화<br>② 독립예술영화 기반 조성 및 지원강화<br>③ 신기술 기반의 창제작 환경 조성 |
| **II. K-무비 공급확대**  | ④ 영화산업 기획개발(R&D) 역량 강화<br>⑤ 경쟁력 있는 중예산영화 지원확대<br>⑥ IP기반 글로벌 경쟁력 육성      |
| **III. K-무비 수요창출** | ⑦ 공정 상생의 산업 환경 조성<br>⑧ 영화 관람 환경 개선<br>⑨ 영화문화 향유 증진과 관객층 확대              |
| **IV. 책임 있는 공공경영** | ⑩ 열린 성과 중심 경영<br>⑪ 고객 중심 경영<br>⑫ 지속가능한 혁신 경영                            |

## 🔗 지표 연계 포인트

### 가. 세부평가내용①과의 연계

> **평가내용**: 설립목적·환경변화에 부합하는 비전·핵심가치·경영목표 설정 및 경영전략의 체계적 수립·이행

#### 1) 비전·핵심가치 연계

| 보고서 작성 항목 | 중장기 전략 연계 내용 | 활용 방안 |
|----------------|---------------------|----------|
| 비전 수립 근거 | "K-무비의 변화와 도약을 함께하는 파트너" | OTT 확산, 디지털 전환 등 패러다임 변화에 대응한 비전 수립 과정 기술 |
| 핵심가치 도출 과정 | 4대 핵심가치(성장과 균형, 도전과 성과, 공정과 확산, 책임과 신뢰) | 새 정부 가치와 기관 성과·한계 극복 기조 반영 근거 제시 |
| 환경분석 방법론 | 4가지 분석 방법(산업생태계, 가치사슬, STEEP, PBMC) | 기존 SWOT 한계 극복을 위한 다각적 분석 방법론 적용 강조 |

#### 2) 경영목표 연계

| 경영목표 | 세부평가 연계 포인트 |
|---------|-------------------|
| K-무비의 지속 성장 기반 강화 | **핵심업무 연계성**: 영화산업 기반 강화를 위한 인력양성, 독립영화 지원 등 |
| K-무비의 국내외 경쟁력 극대화 | **국정과제 반영**: K-컬처 전략산업화, 글로벌 경쟁력 강화 |
| 영화산업 선순환 구조 확보 | **공공성·효율성 균형**: 공정환경 조성 + 산업 활성화 동시 추구 |
| 책임과 합리적 조직경영 실현 | **ESG 경영 요소**: 지속가능한 혁신경영, 윤리경영 강화 |

#### 3) 전략체계 연계

| 편람 요구사항      | 중장기 전략 활용 내용                         |
| ------------ | ------------------------------------ |
| 비전→전략→과제 연계성 | 4대 전략방향 → 12대 전략과제 → 28개 실행과제 체계도 활용 |
| 전략과제별 자원배분   | LV4 내역사업명과 예산·인력 배분 연계표 작성           |
| 이해관계자 공유 활동  | 전략체계 내재화 계획(전사 공유, 핵심가치별 우수사례 발굴) 활용 |

### 나. 세부평가내용②와의 연계

> **평가내용**: 경영혁신 및 경영성과 개선을 위한 계획 수립과 이행

#### 1) 경영혁신 연계

| 혁신 항목   | 중장기 전략 연계 내용                              |
| ------- | ----------------------------------------- |
| 적극행정 추진 | 전략방향 IV "열린 성과 중심 경영" → 성과중심 조직관리 실행과제    |
| 규제개선 노력 | 전략과제 ⑦ "공정 상생의 산업 환경 조성" → 공정환경 조성 법제도 개선 |
| 서비스 혁신  | 전략과제 ⑪ "고객 중심 경영" → 고객 만족도 향상 실행과제        |

#### 2) 환류체계 연계

| 환류 항목 | 중장기 전략 활용 내용 |
|----------|-------------------|
| 이행사항 점검 | 연중 환경변화에 따른 전략 세부사항 상시 모니터링 실시 |
| 혁신계획 연계 | '26-'30 중장기 경영전략 기반 혁신계획(안) 사례 발굴 |
| 환류 계획 | 내부만족도 조사 '경영전략' 부문 결과 바탕 차년도 개선사항 도출 |

## 📊 환경분석 방법론 활용

### 가. 4가지 분석 방법론과 보고서 연계

> 중장기 전략에서 적용한 새로운 분석 방법론을 보고서에 활용하여 **환경분석의 객관성 강화**

| 분석 방법론 | 분석 목적 | 보고서 활용 포인트 |
|------------|---------|------------------|
| **산업 생태계 변화 분석** | 전통적 가치사슬 해체와 새로운 생태계 형성 | 극장→OTT 전환, 네트워크형 유통구조 변화 대응 |
| **새로운 가치사슬 분석** | Porter 5 Forces + 플랫폼 경제학 결합 | 디지털 기술 기반 가치 창출 지점 발굴 |
| **STEEP + 시나리오 플래닝** | 사회·기술·경제·환경·정치 요인 분석 | 3가지 시나리오(낙관/현실/비관)별 대응전략 |
| **Platform Business Model Canvas** | 플랫폼 생태계 중심 비즈니스 모델 설계 | 역할 재정의(지원→생태계 조성자) |

### 나. 시나리오별 대응 전략

| 시나리오 | 확률 | 핵심 대응 | 보고서 기술 방향 |
|---------|-----|---------|---------------|
| **낙관** (K-콘텐츠 황금기 지속) | 30% | 글로벌 확장 가속화 | 한국영화 수출 확대, 제작편수 회복 목표 |
| **현실** (점진적 디지털 전환) | 50% | OTT-극장 상생 모델 | 기존-신규 생태계 공존 전략 |
| **비관** (산업 생태계 위축) | 20% | 독립영화 생태계 보호 | 위기관리 체계, 플랫폼 종속 방지 |

### 나. 핵심 작성 포인트

#### 1) 비전체계 기술 시

```
✓ 미션: 영비법 제1조, 제4조 설립근거와 연계
✓ 비전: K-무비 브랜드 + 변화(디지털 전환) + 도약(글로벌 위상) + 파트너(공정성)
✓ 핵심가치: 4대 가치별 의미 및 행위지표 구체화
```

#### 2) 전략체계 기술 시

```
✓ 4대 전략방향-12대 전략과제-28개 실행과제 체계 명시
✓ 전략과제별 LV4 내역사업명까지 연계하여 구체성 확보
✓ 주요사업(1~3번)과 전략방향(I~III)의 매핑 관계 제시
```

#### 3) 환경분석 기술 시

```
✓ SWOT 한계 극복을 위한 4가지 신규 분석방법론 적용 배경
✓ 영화산업 구조적 변화(OTT 확산, 관객 감소, 투자 위축) 분석
✓ 시나리오별 대응전략 수립으로 불확실성 대비 역량 강조
```

## 📈 주요사업과의 연계 매핑

| 전략방향 | 연계 주요사업 | 세부 연계 내용 |

| **I. K-무비 기반강화** | 주요사업 1, 2 | 한국영화 제작·유통 활성화, 혁신성장 기반강화 |
| **II. K-무비 공급확대** | 주요사업 1, 2 | 중예산영화 지원, 기획개발 역량강화, 글로벌 진출 |
| **III. K-무비 수요창출** | 주요사업 3 | 영화문화 가치확산, 관객개발, 관람환경 개선 |
| **IV. 책임 있는 공공경영** | 경영관리 전 지표 | 조직운영, 재무관리, 국민소통, 윤리경영 |
