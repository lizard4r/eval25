## 📊 세부평가내용① 연계 - 비전·경영전략 이행

### 가. 비전-전략-과제 연계 체계

```
┌─────────────────────────────────────────────────────────────┐
│  비전: 영화문화의 창조적 혁신을 이끄는 영진위                   │
├─────────────────────────────────────────────────────────────┤
│  전략방향 1          │  전략방향 2          │  전략방향 3     │
│  한국영화 글로벌     │  산업생태계 건전화   │  영화 다양성    │
│  경쟁력 강화         │  및 지속가능성 확보  │  확보           │
├──────────────────────┼──────────────────────┼─────────────────┤
│  정책개발팀 연구과제                                           │
│  ┌──────────────────┐ ┌──────────────────┐ ┌───────────────┐ │
│  │ 북미 진출 연구   │ │ 홀드백 분석     │ │ 독립예술영화  │ │
│  │ (공동제작 활성화)│ │ 기획개발 연구   │ │ 생태계 연구   │ │
│  │                  │ │ 소비트렌드 연구 │ │ 영화제 발전   │ │
│  └──────────────────┘ └──────────────────┘ └───────────────┘ │
└─────────────────────────────────────────────────────────────┘
```

> 💡 **정책개발팀 7개 연구과제 전체**가 기관 비전-전략방향과 직접 연계

### 나. 중장기 경영전략 연계 연구 추진

#### 1) 한국영화진흥 기본계획 연계

| 기본계획 방향        | 연구과제 연계                             |
| -------------- | ----------------------------------- |
| **글로벌 경쟁력 강화** | 『한국영화 북미지역 진출 및 공동제작 활성화 지원방안 연구』   |
| **산업생태계 건전화**  | 『홀드백 분석 연구』, 『기획개발 현황 및 지원방안 연구』    |
| **다양성 확보**     | 『독립예술영화 생태계 구축 정책연구』, 『영화제 발전방안 연구』 |

#### 2) 정책연구심의위원회 운영

| 운영체계 | 내용 |
|---------|------|
| **연구과제 선정** | 정책연구심의위원회 심의를 통한 과제 선정 ('25.2.24.) |
| **연구결과 평가** | 위원회 전체 연구과제 통합관리 체계 |
| **활용상황 점검** | 연구결과 활용 모니터링 및 환류 |

> ✅ **부서별 현안과제 중심** 연구과제 시의성 제고 및 중복과제 관리

### 나. 대내외 이해관계자 의견수렴

#### 1) 연구과제 수요조사 체계

| 대상 | 수렴 방식 | 접수 실적 |
|------|---------|:--------:|
| **대국민** | 연구과제 제안 공개 모집 ('25년 신규) | 8건 |
| **유관기관·협단체** | 공문 발송 및 의견 접수 | 8건 |
| **위원회 위원** | 전문가 제안 | 2건 |
| **내부 유관부서** | 부서별 수요조사 | 7건 |
| **합계** | - | **25건** |

> 💡 **'25년부터 대국민 연구과제 제안 접수** → 아이디어 개발 접근성 확대

#### 2) 부서별 연구과제 검토 워크숍

| 시기 | 참여부서 | 주요 논의 |
|------|---------|---------|
| '24.11~12월 | 사업본부 3팀 + 정책본부 2팀 + 공정환경조성센터 | 부서별 연구 수요 상세 의견수렴 |
| '25.1~2월 | 정책개발팀 내부 | 연구추진계획 점검 워크숍 |

## 📊 세부평가내용② 연계 - 경영혁신 및 경영성과 개선

### 가. 적극행정 추진

#### 1) 현장 중심 연구 수행

| 연구과제         | 적극행정 내용                          |

| **소비트렌드 연구** | 국내 3,000명 + 해외 4개국 800명 대규모 설문조사 |

| 『통전망 통계집계기준 연구』 | **'26년 통전망 집계체계 개편 확정**               |
| 『기획개발 연구』       | '27년 기획개발 예산편성 및 사업계획 수립 시 반영 예정      |

#### 1) 전사적 경영전략 점검 워크숍 지원

| 조사활동 | 활용 |
|---------|------|
| 『한국영화 투자 및 제작 현황 조사』 | **전사적 경영전략 실행 점검 워크숍** 핵심 기초자료 |
| 업계 11개사 심층인터뷰 | 대내외 환경변화 대응 기관 역할 재설정 |

#### 2) 연구 자체평가 및 환류 체계

| 환류 항목 | 내용 |
