## 📊 세부평가내용③ 연계 - 정보보안 관리 (핵심 연계)

### 가. 정보보안 관리체계 강화

#### 1) 정보시스템 노후 인프라 정비

| 시스템 | 개선내용 | 완료시기 |
|--------|---------|---------|
| 대표홈페이지 | Windows 기반 DB서버 → Oracle DBMS(Linux) 변경, 통합DB 이관 | 2025.3. |
| 기획개발센터 S#1 | Windows 기반 DB서버 → Oracle DBMS(Linux) 변경, 통합DB 이관 | 2025.5. |
| 영사검정자격시스템 | Windows 기반 DB서버 → Oracle DBMS(Linux) 변경, 통합DB 이관 | 2025.12. |
| 그룹웨어시스템 | 2011~2013년 서버 → 2025년 신규 서버 교체 | 2025.12. |

> ✅ **노후 Windows 서버 Linux 전환 → 보안취약점 해소**

#### 2) 그룹웨어시스템 보안 강화 ('25.9.~12.)

| 구분 | AS-IS | TO-BE |
|------|-------|-------|
| 서버 | 2011~2013년 도입 | 2025년 신규 서버 |
| 그룹웨어 | v8 | v10 |
| 사내 메신저 | v6 | v7 |
| 한글오피스 | 2014 버전 | 2025 버전 |
| 보안 기능 | OCX 컨트롤 의존 | 웹한글기안기 도입 |

> 💡 **한컴오피스 OCX 컨트롤 지원 중단 대응 → 웹한글기안기 도입**

#### 3) 내부 클라우드 보안 체계 구축

| 단계 | 내용 | 보안 효과 |
|------|------|---------|
| 1단계 | 클라우드 인프라 구성 | 중앙 집중 보안관리 기반 마련 |
| 2단계 | 서비스영향도 평가 | 보안 취약 서비스 식별 |
| 3단계 | 노후 서버 이관 | 10년+ 노후 서버 39대 보안 강화 |
