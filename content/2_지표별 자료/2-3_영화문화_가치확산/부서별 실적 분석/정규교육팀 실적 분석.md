## 📊 주요 실적

### 1. 졸업영화제 '영화로운' (지역 문화행사) ⭐

#### 1-1. 행사 개요

| 항목 | 내용 |
|------|------|
| **일시/장소** | 2025.3.7.~3.9. / 메가박스 성수, Kofic 표준시사실 |
| **상영작품** | 장·단편영화 **38편** |
| **관객수** | **2,681명** |
| **좌석점유율** | 장편 기준 **95%↑** |
| **후원** | 플러스엠 단독후원 |

#### 1-2. 영화문화 가치확산 연계 효과

| 구분 | 내용 |
|------|------|
| **관객 접근성** | 일반 관객 대상 신진 창작자 작품 공개 |
| **산업 연계** | 졸업생과 산업관계자(투자/제작/배급) 네트워킹 |
| **브랜드 강화** | KAFA 산업 내 인지도 제고 |

### 2. Netflix 지역 마스터클래스 ⭐

#### 2-1. 네오소라 감독 마스터클래스 (부산)

| 항목 | 내용 |
|------|------|
| **대상** | 재학생, **부산지역 예비 영화인** 등 **61명** |
| **내용** | 영화 <해피엔드> 심층분석 및 창작과정 공유 |
| **강사** | 네오소라 감독 (동시대 가장 주목받는 신진 일본 감독) |

> 🎯 **지역 기여**: 부산지역 예비 영화인 대상 교육 기회 제공 → **지역 영화문화 접근성 확대**

#### 2-2. 리부트캠프

| 항목 | 내용 |
|------|------|
| **대상** | 졸업생 10명 / 재학생·교수진 25명 |
| **강사** | 할리우드 작가 겸 PD 조 페라키오, 감독 마이클레만 |
| **만족도** | **4.5점/5.0점** |

---

### 3. 글로벌 영화문화 교류 ⭐

#### 3-1. 해외 영화학교 협력

| 프로그램 | 참가인원 | 성과 |
|---------|:-------:|------|
| 한-프 영화아카데미 | **12명** | 장편 프로젝트 기획개발, 칸영화제 연계 |
| 한-일 글로벌 워크숍 | **18명** | TIFFCOM 피칭 **1등상** 수상 |
| 글로벌과정 (신규) | **8명** | 국제공동제작 단편 4편 제작 |

#### 3-2. KAFA 교육 글로벌 진출

| 항목 | 내용 |
|------|------|
| **사우디 마스터클래스** | 현지 신진 창작자 **10명** 교육 |
| **만족도** | **8.75점/10점** |
| **의의** | 한국 영화교육 모델 국제적 확산 |

> 🌏 **문화 확산**: KAFA 교육 프로그램 글로벌 확장 → 한국 영화문화 국제적 확산
