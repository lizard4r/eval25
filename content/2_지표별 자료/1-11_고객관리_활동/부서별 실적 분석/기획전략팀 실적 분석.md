## 🎯 고객관리 전략체계 재수립 ⭐

### 1. 재수립 배경

| 배경 | 내용 |
|------|------|
| **기존 문제** | 위원회 고객관리 전략체계 부재 |
| **환경 변화** | 영화 산업의 급변으로 고객관리 전략체계 고도화 필요 |
| **필요성** | 중장기 경영전략체계에 따른 새로운 고객관리 전략체계 마련 |

### 2. 재수립 프로세스

```
고객감동추진단 운영 → 고객관리 전략체계 수립(안) 검토 → 경영진 보고 → 전사 배포
      (8~10월)              (9~10월)                 (10월)      (10.1.)
```

### 3. 환경분석 혁신 ⭐ (신규)

#### 기존 → 개선
| 구분 | 기존 | 개선 |
|------|------|------|
| 분석 범위 | 이해관계자 니즈 분석 | **PEST 분석 + 고객 분석** (거시/미시 확대) |

#### PEST 분석 (거시환경)
| 요소 | 분석 내용 |
|------|----------|
| **P (정치)** | 정부 주도 문화강국 실현 목표로 직접적 지원 확대 |
| **E (경제)** | 극장·영화 산업 회복세 더딤 |
| **S (사회)** | OTT 산업 확대, 넷플릭스 한국 콘텐츠 파급력 |
| **T (기술)** | AI 기반 영화 제작·영화제 확산, 몰입형 상영 포맷 확대 |

#### 미시환경 분석
| 대상 | 분석 내용 |
|------|----------|
| **소비자** | OTT, 숏폼 중심 소비 변화, 입소문 영향 확대, 특화관 선호도 증가 |
| **투자자** | 수익률 악화로 영화 투자 매력 감소, 투자-제작-배급 악순환 |
| **언론** | 긍정 보도 우위, 정책 한계·투명성 이슈 등 부정 논조 존재 |
| **창·제작자** | 산업 내 일자리 부족으로 인한 인력 유출 |

| **제작자** | 영화 제작에 직·간접적으로 참여하는 고객 (제작사, 프로듀서) |
| **투자사** | 영화 제작 자금을 공급할 수 있는 고객 (투자조합, 민간 기업체) |
| 외 9개 | 배급사, 극장종사자, 현장영화인, 예비영화인, 일반국민 등 |

### 5. 고객관리 전략체계 구조

#### CS 비전 및 목표
| 구분 | 내용 |
|------|------|
| **CS 비전** | 고객 중심 서비스로 감동을 실현하는 K-무비의 파트너 |
| **CS 목표 (정량)** | 고객만족도 최고등급 '우수' 달성 |
| **CS 목표 (정성)** | 고객의 니즈에 기반한 맞춤형 서비스로 최고 수준의 고객만족 실현 |

#### 3대 CS 전략 및 과제
| CS 전략 | CS 과제 |
|---------|---------|
| **가. 고객 중심 지원 체계 강화** | 1) 수요와 일치하는 서비스로 혁신<br>2) 지속적 고객관리 및 VOC 해소 |
| **나. 고객소통 강화** | 1) 범영화계 정책제안 공조 반영<br>2) 고객 경영참여 강화 노력<br>3) 소통창구 관리강화 |
| **다. 공공기관의 지속가능성 추구** | 1) ESG 경영 확산<br>2) 윤리경영 이행 |

#### CS 성과지표
| 유형 | 지표 |
|------|------|
| **계량** | 고객만족도 점수, CS교육 이수자 비율, 소통 채널 운영 건수 |
| **비계량** | 고객 중심 정책 추진 노력도 |
