## 📋 안전관리 추진체계 및 핵심과제

### 가. 안전관리 핵심 방향

> **(안전한 안심일터 마련) 체계적 안전관리로 재난대응체계 확립, 중대시민재해 및 안전사고 예방**

### 나. 2025년 기관안전 기본방향

| 핵심방향 | 추진내용 |
|---------|---------|
| **현장점검 체계 확립** | 현장점검 → 개선조치 → 재점검 체계 확립 |
| **안전경영책임계획 연동** | 분기별 「안전점검의 날」 운영결과를 연간 안전경영책임계획과 연동 |
| **점검범위 확대** | 본사, 부산촬영소, 한국영화아카데미, 영화교육지원센터 등 |
| **계절·이벤트별 테마형 점검** | 해빙기, 장마철, 폭염, 대형행사(영화제 등)에 따른 중점위험 설정 |

### 나. 위험성평가 실적

#### 1) 위험성평가 개요

| 구분       | 내용                                     |
| -------- | -------------------------------------- |
| **근거**   | 「산업안전보건법」 제36조                         |
| **평가대상** | 본사 사옥, 한국영화아카데미 사옥(부산, 서울), 부산촬영소 건설현장 |
| **평가기간** | 2025년 5월 8일 ~ 10월 31일                  |
| **평가방법** | 가능성·중대성 3단계(상·중·하) 평가, 위험도(1~9점) 산출    |
| **관리기준** | 위험도 6점 이상 → '즉시 개선' 등급 분류              |

#### 2) 위험성평가 개선 성과

| 구분 | 개선 전 | 개선 후 |
|------|:------:|:------:|
| 위험도(높음): 7~9단계 | 7건 | **1건** |
| 위험도(보통): 4~6단계 | 7건 | 4건 |
| 위험도(낮음): 1~3단계 | 3건 | **12건** |
| **위험도(낮음) 비중** | 18% | **71%** |

> ✅ **총 17건의 유해·위험요인 평가 → 위험도 대폭 저감**
